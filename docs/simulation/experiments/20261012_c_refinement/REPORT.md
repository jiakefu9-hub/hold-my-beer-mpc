# C 前馈加速度 PID：细化、取舍与首次真机准备

2026-10-12。仅仿真、无网络日志回放和软件验证；没有连接或运行机器人。
当前原 MPC 与旧 C 均保留。用户最后明确希望允许少量姿态退步来换取加速度改善，
因此最终筛选没有继续优先追求最小倾角。

## 结论

共 163 次完整任务仿真尝试，145 次正常完成，18 次控制失败；其中 110 次调参、53 次复核/重复。
另有 18 次在初始化前因 /tmp 原生库缺失而失败，未运行物理轨迹，单独归档且不计入仿真次数。
重建后旧 C 六项结果与原结果一致。

没有找到同时大幅改善六项指标的 C。放松姿态确实可降低线加速度，但收益有限，
且部分组合增加角速度、出现肩部接触，或在条件手臂模型的接管阶段触及边界。
不能将这些组合直接晋升为上机配置，也不能以调参结果宣称 MPC 或 C 全面优越。

最终上机候选选择 **C_field_candidate**：适度降低任务姿态 PID 的 P/D，增加关节回中，
保留单拍受约束分配与已有提前制动。它不是仿真最低加速度的组合。
标准场景及 75 mm 场景无手臂接触、无物理关节越界；对两条真机身体运动的条件手臂模型检查通过。
4 ms 延迟的完整机器人仿真仍记录短暂肩部接触，因此不能宣称延迟鲁棒性已解决。

## 同一 0～8 s 完整任务的指标

主表为原 200 mm、250 g 仿真负载。倾角为每帧瓶轴相对世界竖直夹角的平均值；
摆动为每帧瓶轴相对归一化平均瓶轴方向的角距离 RMS。其余均为三维向量 RMS。
线速度包含正常向前行走，不能简单将它下降解释为控制改善。

相对旧 C，最终上机候选线/角加速度分别降低 **0.82% / 1.04%**，角速度增加 **11.88%**；
两种倾角增加约 **0.045° / 0.051°**。不能把它描述成六项全面改善。
“放松姿态、旧裁剪结构”可降低线加速度 3.65%、角加速度 3.91%，但角速度增加约 30.5%，
且该仿真结构没有真机需要的分配内力矩约束，未直接提供上机入口。

|---|---:|---:|---:|---:|---:|---:|
| 左固定 PD | 4.75929 | 2.43571 | 2.36168 | 10.73338 | 0.46550 | 0.36250 |

右端线加速度仍比同轮左端高约 25.5%，优势主要是倾角与角运动；不隐去这一结果。
各个方案自己的左右臂全表见 [METRICS.md](METRICS.md)，不要将某一轮左臂冒充所有方案相同的测量结果。
原 MPC 的运动范围较窄，保守 MPC 与 C 的范围相同，另两组优化 MPC 放宽更多；
上述差异不能全部归因于是否使用滚动优化。

## 实际参数修改

下表的 PID 是末端任务反馈，**不是 Arm SDK 底层 Kp/Kd**。

| 参数 | 旧 C | 仅仿真放松姿态版 | 最终上机候选 |
|---|---:|---:|---:|
| 任务姿态 Kp | 900 | 150 | 400 |
| 任务姿态 Ki | 50 | 50 | 50 |
| 三轴角速度 Kd | 60 | 25 | 40 |
| 线加速度分配权重 | 0.1 | 0.4 | 0.4 |
| 分配正则权重 | 0.003 | 0.012 | 0.012 |
| 关节回中 kp / kd | 4 / 2 | 4 / 2 | 24 / 8 |
| 积分限幅 | ±0.1 | ±0.1 | ±0.1 |
| 分配方式 | 求解后逐关节裁剪 | 同旧 C | 约束内重新分配，限幅时冻结积分 |
| 提前制动 | 无独立分配内制动 | 同旧 C | 复用既有制动 |

提高关节回中约束的是偏离中立关节角的运动，不是把瓶轴竖直权重重新提高。
它主要消除了标准/另一初态的肩部短暂接触，代价是收回部分加速度收益。
没有改左臂、腿部任务、控制周期或物理力矩上限来制造对比差异。

C 仍是任务 PID + 单拍控制分配：

`min_a ||Jw*a+b_alpha-alpha_PID||² + wa*||Jv*a+b_acc||² + reg*||a-a_posture||²`。

未来身体加速度只使用首区间；不优化九步关节轨迹。
仿真原接口中的 MPC 权重对 C 不生效，按上表的 simple_apid_* 参数识别实际控制器。
仿真仍为 6 ms 控制、2 ms 物理步，dq=2 rad/s、期望 ddq=15 rad/s²。
仿真使用原有模板预览处理；真机使用 H0 learned_filtered，二者不是同一套数据或预测链。

## 分阶段探索及不采用项

1. round1：24 次单因素，改变任务 P/D/I、线加速度权重、正则与回中。
2. round2：24 次组合和预测前视。姿态最好的 r2_mix_7 并没有更低线加速度。
3. round3：24 次单拍受约束分配和局部参数，发现只加下一拍边界不足以避免后续不可行。
4. round4：12 次加入已有提前制动。保留完整失败记录，不增加物理力矩来强行完成。
5. 用户提出允许姿态退步后，round5：18 次降低任务反馈增益，观察加速度与角运动取舍。
6. round6：8 次检查旧裁剪与受约束分配、回中强度，筛除标准场景有接触的候选。
7. 共 53 次复核包括另一初态、4 ms 指令延迟、75 mm 负载、约束消融、重建一致性和重复。

163 次中失败的 18 次主要是下一拍边界不可行或执行层 NO_SAFE_TORQUE；
列表见 [run_counts.json](run_counts.json)。不能只按“程序完整结束”判定可上机，
还核查了接触、关节与力矩。
更软的 150/25、回中 24/8 候选在条件手臂模型一例中于约 4.115 s 触及 yaw 外边界，暂不选。
这是假设模型检查中的失败，不宣称它已经在真实机器人上失败。

最终候选：标准、另一初态、75 mm 三组均无手臂接触/物理关节越界。
4 ms 延迟组虽完整结束，但有 21 帧（2 ms/帧）肩 yaw 连杆与躯干接触，保留为局限，
不能拿它作为无接触稳定或实机延迟鲁棒性的证据。完整数据见
[VALIDATION_METRICS.md](VALIDATION_METRICS.md) 与 [final_candidate_contacts.json](final_candidate_contacts.json)。

## 真机迁移范围和离线验收

独立 `configs/hardware_acceleration_pid_20261012.yaml`，仅显式选择 C 才生效。
原 164546 配置和 01～08 配置保留；200 拍与保存的原运行时比对，指令最大差为 0。
该结论只验证未选择 C 的原路径未变，不等于原配置与新 C 输出相同。

真机使用带实测移动基座输入的耦合右臂五自由度模型；分配内同时限制总力矩和发包前馈力矩。
保持原 `[10,6,4,7,1.5] Nm`、dq=5 rad/s、ddq=15 rad/s² 及原关节外边界。
复用原肩关节内外边界余量，已来不及在内边界停住时在原外边界内制动，不扩大外边界。
发包 `tau=M*a+b-packet_PD`，固件只补回一次 PD。
真机还包括上述力矩行和边界余量逻辑，因此不是与仿真逐位相同的实现。
sim ±25 Nm 的限值不能直接搬到真机。

最终参数通过 75 项现场相关回归测试、7 项仿真控制器测试、两条完整无网络历史输入回放，
以及两条实测身体输入 × 0/4 ms 的四组条件手臂模型闭环检查。
历史回放的记录 q/dq 不响应新指令；条件模型虽响应指令，却没有标定电机、接触、传感噪声及臂到躯干反作用。
两者均不证明实机性能或真实 6 ms 调度；现场仍是 C 的首次实验。
最终完整仿真第一次计时与其他验证同时运行，出现21/1329次6 ms超期，原记录保留。
停止其他实验后在CPU 7单独复测：均值2.978 ms、p99为3.665 ms、最大4.014 ms、0次超期，
六项运动指标与前次一致。不能以该单次复测代替真实DDS、进程调度及电机时序验收。
测试日志、配置副本与离线验收汇总见
[现场证据](../../../g1_field_validation/evidence/20261012_c_preparation/README.md)。

不把 C 调参扩展成另一轮现场大扫描。时间对齐开启时只调整首区间身体线/角加速度取样，
不修改当前实测状态或加入新的姿态预测校正。
