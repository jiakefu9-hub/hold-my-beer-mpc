# 三组仿真展示：位置 PID、预测消融 MPC、预测前馈 MPC

2026-11-03。只运行了仿真，没有连接或控制机器人。原真机代码、默认配置及历史数据不变。

## 选的是哪三组

| 编号 | 右臂控制 | 选择依据 |
| --- | --- | --- |
| D01 | 原位置 PID，输出关节位置/速度参考给底层 PD | 沿用 20261011 的 `s06_original_pid`，不重新调差，也不声称是 PID 家族最佳 |
| D02 | 加速度 MPC，整个窗口保持当前测得的身体扰动 | 与 D03 的配置仅一个布尔值不同，用于检验未来扰动预测的作用 |
| D03 | 加速度 MPC＋历史模板未来扰动预测 | 选 20261010 的 `s002_solver` 思路：原目标函数和活动范围，仅提高数值求解精度 |

**三组都是左臂固定关节 PD、右臂主动控制。左右指机器人自身左右，不能按正面画面的左右判断。**

选择 D03 的标准是姿态表现好、保留原控制结构、少引入真机最终未采用的功能，不是宣称全局最优。
之前的保守范围/加速度综合/姿态综合三个优化组合都引入了姿态预测校正和时间前视，部分还扩大关节活动范围；本次不将它们作为主展示。

D02 不是“取消所有前馈”：仍保留当前身体 IMU 扰动、重力及原逆动力学执行。
隔离适配器将当前扰动重复到全部 10 个节点和 9 个区间，D03 才使用未来模板值。
适配器仍计算原模板并保留部分预测诊断，所以不能把 D02 的模板诊断字段当作该组优化器实际使用了模板预测的证据。

## 配置究竟改了什么

两组 MPC 相对原仿真基线的有效控制变化只有 OSQP 数值设置：

| 配置 | 原仿真基线 | D02 / D03 |
| --- | --- | --- |
| `mpc_osqp_eps_abs` | 1e-3 | 1e-4 |
| `mpc_osqp_eps_rel` | 1e-3 | 1e-4 |
| `mpc_osqp_max_iter` | 400 | 4000 |
| 线加速度/角加速度/角速度代价 | 0.01 / 0.0005 / 8 | 不变 |
| 端平代价 | [30,30] | 不变 |
| 回中代价 | [4,4,1.5,0.2,0.2] | 不变 |
| 控制周期 / 预测区间 | 6 ms / 9 | 不变，54 ms 窗口 |
| 姿态预测校正 / 区间前视 | 关闭 / 0 ms | 明确关闭 / 0 ms |
| MPC 速度 / 期望加速度上限 | 1 rad/s / 8 rad/s² | 不变 |

4000 是允许的最大迭代数，不是每拍必须执行的次数。第一次用历史 `s002_solver` 的 1500 上限时，D02 有一次迭代上限回退；因此**两组同时**提高到 4000。D03 的完整轨迹和六项指标均保持不变。最终两组都无 QP 失败，没有通过放松物理限制消除回退。

`research_hold_future_disturbance` 是 D02 / D03 唯一配置差异（true / false）。`simple_controller` 只是隔离仿真入口的控制器选择标签。

MPC 扣除 margin 后的角度区间，顺序为肩 pitch、肩 roll、肩 yaw、肘 pitch、腕 roll：
`[-4,4]、[-4,2]、[-20,5]、[-40,40]、[-40,40]°`。没有采用优化组合里的 ±15° 肩 roll。

D01 保留原位置 PID：`kp=[1.2,1.2]、kd=[1.2,1.2]、ki=[0,0]`，原回中增益、滤波、`pid_max_dq=0.48` 不变。
“PID”沿用仓库命名，原积分增益本来就是零。沿用该历史适配器的参考角裁剪区间：
`[-15,15]、[-15,15]、[-20,15]、[-40,40]、[-40,40]°`。
该参考范围比两组 MPC 宽；没有为了削弱 PID 而缩窄。PID 与 MPC 的参考/加速度限制不是同一种物理量，不能声称已证明各控制器最佳性能的严格排名。
配置里保留的 MPC 成本键不进入 D01 的 PID 控制律。去掉旧配置中无用的预测校正/前视后，D01 复现了历史的数值结果。

三组共同保持原零中立位、正常仿真左臂 PD、腿部策略、初态、行走命令、物理模型和力矩限值。
腿部实际闭环轨迹会随手臂控制略有变化，不是强制完全相同的身体运动回放。

## 与真机相同和不同的部分

- 同类架构：6 ms、9 区间、关节 q/dq 状态、ddq 输入、多目标 MPC、逆动力学执行。
- 未增加真机最终未采用的姿态预测校正、时间对齐、状态外推、控制升频或更长窗口。
- **沿用历史仿真的 200 mm / 250 g 负载模型**，没有偷偷替换成 75 mm。最终真机是 75 mm / 250 g 模型；本次是原仿真研究的展示复跑，不是最终真机附件的数字孪生。
- 仿真使用历史任务扰动模板，真机使用 H0 学习预测器；两者数据、坐标处理、滤波和执行模型不同。
- 仿真角速度代价 8、真机 1 只在各自目标函数中解释，不能比较为八倍控制作用。
- 仿真保留 MuJoCo 正动力学候选检查；真机是带实测移动基座输入的耦合右臂五自由度动力学模型。
- 本批同步仿真按物理时间推进；主机计算慢不会自动成为电机延迟。本次不是硬件实时验收。

相对 D02，D03 的两种倾角降低 82.0% / 81.1%，线加速度降低 11.2%，角加速度降低 29.6%，角速度降低 61.1%；绝对线速度基本持平，略高 0.1%。线速度包含共同前进运动，不是越小就一定越好。

D01 的两种倾角也比 D02 小，**不能声称这三组的每项指标都按 PID→无预测 MPC→预测 MPC 依次变好**。
D03 的姿态和角运动明显优于同轮左手，但线加速度仍高于左手。这些限制保留，不用视频遮盖。
位置 PID 不是同执行层前馈 PID（C）；C 的既有结果仍在原研究中，没有删除，也不能凭这里的 D01 断言 MPC 优于所有 PID 变体。

竖直倾角是每帧末端 +Z 与世界 +Z 的夹角的均值。平均轴摆动是每帧 +Z 相对于归一化平均轴的角距离 RMS，保留了方向信息。
原始轨迹、同定义全程/行走/停车分段指标见各 `D0*_metrics.json`；整表见 `metrics.csv`。
这些仿真加速度不能替代真机的离线重建、滤波后指标。

## 验证与保留的限制

最终三个任务均完整结束，`full_task_smoke_summary` 为 PASS，无摔倒、NaN 或 QP 失败。
MPC 执行层仍使用既有安全候选回退：D02 7 次、D03 2 次。因此 PASS 不等于没有任何执行回退。
本次实际执行五次仿真：原 PID 一次，1500 迭代上限的 MPC 配对两次，4000 上限的配对两次；初次 D02 的回退记录未删。
`selection_checks.json` 保留选择过程与检查结果。

本机普通调度 CPU 2 的完整右臂计算区间（含预测与执行层，不含物理推进/绘图）：D02 p99/max 为 4.193/18.899 ms，2/1329 拍超过 6 ms；D03 为 4.075/5.973 ms，0/1329 拍超期。D02 的数值求解预算因此不能直接当作真机实时配置；本次同步仿真不把这些墙钟超期自动注入物理时间。没有用这批数据声称全部方案满足实时要求。

回放存储实测仿真 qpos/qvel/time。文件哈希、模型哈希、配置差异及正运动学验证通过；离屏渲染已检查。图形窗口仍需在本地图形桌面打开。
回放每帧只执行正运动学刷新，不重新解 MPC，也不与机器人通信。

## 重新计算

已有小回放包可直接使用；只有要重新算物理仿真时才需构建和启动计算：

```bash
bash cpp/build_runtime.sh
/home/fjk/miniforge3/envs/g1_mpc/bin/python tools/experiments/simulation_showcase/run_study.py tools/experiments/simulation_showcase/cases.json --cpus 2
/home/fjk/miniforge3/envs/g1_mpc/bin/python tools/experiments/simulation_showcase/package.py
```

研究入口会复用相同名称的缓存；如要真正重跑，在 `cases.json` 中给实验名称增加独立后缀，保留原结果。
默认只保留新运行的必要紧凑数据；`--keep` 可保留新运行的所有大文件。不会清理旧研究或真机数据。
