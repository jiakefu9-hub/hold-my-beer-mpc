# Historical stiff-left showcase baseline

This directory preserves the immediately preceding D01-D03 portable replays,
metrics, manifest, and exact run configs before the left-arm nominal simulation
PD gains were unified to `Kp=20`, `Kd=1` on 2026-11-03. The historical left
five-joint gains were `Kp=[80,80,60,80,30]` and `Kd=[5,5,3,2,1]`.

These files are historical comparison evidence. The parent directory's D01-D03
files are the current `20/1` showcase results.
