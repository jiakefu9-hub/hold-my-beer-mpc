# 位置 PID 加速度核对与 D01 更新

2026-11-03。仿真与离线分析，不修改真机或主控制器代码。完整机器可读结果：`pid_audit.json`。

## 原来的 9.419 是不是错的

不是算错单位或把重力加进去。旧 D01 的线加速度来自世界系末端速度相邻 2 ms 差分，再取三维向量模 RMS，窗口为完整 `[0,8)`。
原记录为 9.4191999 m/s²，重新用保存的 qpos/qvel、更新后的雅可比计算 `v=Jv*dq` 再差分，得到 9.4196554 m/s²，RMS 相差约 0.0048%。
逐样本存在小差异，不宣称逐位一致；重新更新几何与原在线记录的采样阶段不同，但不影响 9.42 这一结论。

这也不是起步某一次尖峰：1–6.4 s 的 RMS 为 9.430，停车 6.4–8 s 为 9.197。重新计算的 XYZ 分量 RMS 约为 2.539、2.960、8.574 m/s²，主要问题在 Z 向。

旧 D01 有持续快速振动：

- 线加速度谱主峰约 12.2 Hz，30 Hz 以上约占 Welch 谱功率的 16.7%。
- 每 6 ms 抽取一拍的目标速度，肩 pitch、肘约 96% 的拍达到 ±0.48 rad/s；肩 roll、腕约 88%。
- 目标速度不断换向。姿态角幅度很小不等于加速度小：较高频率的小幅振动仍能产生较大的加速度。
- 降低同一控制律的反馈增益后，饱和与高频谱功率一起下降，支持“过强纠偏引起饱和振动”这一诊断；不是单靠观察一个大 RMS 猜测。

旧基线并非单纯的坏数据，但不宜不加解释就把它当作位置 PID 的代表性能。上次选择只核对了历史结果复现，没有充分检查这种饱和振动，现已补齐。

## 为什么真机没有这么大

仿真 D01 和真机位置 PID 共用核心公式，但外围处理不同：

1. 仿真按 6 ms 计算 `dq_task=delta_q_task/dt`，原导数滤波每拍系数 0.07。
2. 真机使用 20 ms 的任务修正参考时间和物理时间滤波换算，6 ms 系数为 `1-(1-0.07)^(0.006/0.020)=0.0215359257`。
3. 真机还对位置参考加了 0.07 rad/s、0.2 rad/s² 限幅；后来的 V04 放宽为 0.14、0.4。原仿真 PID 只有核心速度限幅 0.48，未经过真机这一层参考加速度限制。
4. 真机指标基于 IMU/关节运动学重建，并使用 105 ms 三阶 Savitzky–Golay 处理；当前仿真指标是 2 ms 速度差分，评价带宽不同。
5. 负载、底层执行、身体运动也不同，不能将全部数值差距归因于某一项。

旧 D01 仅在离线将速度作约 105 ms 平滑后再求导，加速度 RMS 会从 9.419 降到 4.560。这只说明带宽敏感性，**不是完整真机评价管线，更不能将 4.560 替换进主对比表**。所有本次方案仍统一使用原始仿真评价方法。

历史数据也不止一个值：`evaluation/left_fixed_right_pid/20260629_150416` 的旧任务窗口为 2.4–8.8 s，右臂加速度 6.086 m/s²，不能混入当前完整走停窗口。
真机 M03/M04 的完整主窗口右臂平均约 1.865 m/s²，见 [六轮真机结果](../../../g1_field_validation/sessions/20261013_MORNING_RESULTS_AND_VIDEO_PLAN.md)。这些事实与本次仿真 9.419 并不矛盾。

## 小范围参数验证

保持全部物理条件、PID 公式、左 PD、速度上限、关节参考范围、6 ms 周期不变。没有加入前馈、优化器或力矩逆解。
原 Ki=0 保持零，PID 名称沿用项目。以下 Kp/Kd 都是两项倾斜反馈增益，两个分量同值；不是底层关节 PD 增益。

新 D01 主要变化证据：

- 线加速度从 9.419 降为 3.191，降低 66.1%；角加速度从 79.744 降为 13.075，降低 83.6%。
- 肩 pitch/肘的目标速度饱和比例降为约 0.52%/0.60%；30 Hz 以上加速度谱功率比例由 16.7% 降为 1.93%。
- 主谱峰从约 12.2 Hz 降为 4.88 Hz。两种姿态角度相应增大，体现平顺性与纠偏速度的折中。
- 五组新参数均完整结束且 PASS。将选中参数写入独立配置后再次复现，完整右臂指标差异为 0。

## 最终展示选择

默认 D01 换成均衡候选，因为它消除了大部分饱和振动，并保留较小的两种倾角。不是因为要求它必须输给 D02。
事实上，新 D01 的线加速度 **3.191 小于 D02 的 3.312**；D01_SOFT 的 **2.816 还小于 D03 的 2.940**。
这些候选都有合理用途，没有按预设排名删掉反例；D03 仍在两种倾角、角加速度和角速度方面明显优于两个新 PID。
这一轮是小范围 PID 折中研究，不是各算法全局最优比较，也没有把前馈 PID C 的结果删除。

回放编号 `D01` / `D01_SOFT` / `D01_OLD` 已全部保留。D02、D03 的回放哈希与本次更新前相同。
