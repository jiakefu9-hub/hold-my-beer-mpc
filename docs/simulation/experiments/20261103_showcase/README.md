**更新：经用户指出原 PID 的加速度异常偏大，已完成原因核对和 8 次补充仿真。D01 现为降低反馈增益、减轻饱和振动的位置 PID；原版保留为 D01_OLD，更柔和候选为 D01_SOFT。三组主展示使用真机的 75 mm / 250 g 圆环模型，并已把左臂五个关节统一改为名义 `Kp=20、Kd=1` 后完整复跑。此前较硬左臂的三组回放和指标保存在 `stiff_left_baseline/`。**

## 选的是哪三组

| 编号 | 右臂控制 | 选择依据 |
| --- | --- | --- |
| D01 | 位置 PID，输出关节位置/速度参考给底层 PD | 原公式不变，降低反馈增益和导数滤波系数，解决旧配置长期速度饱和；兼顾姿态和动态指标 |
| D02 | **No-Preview MPC**：每拍使用实测状态和当前身体扰动，预测窗口内保持当前扰动 | 与 D03 的配置仅一个布尔值不同，用于检验未来扰动预览的作用 |
| D03 | **Disturbance-Preview MPC**：使用历史模板提供未来身体扰动 | 选 20261010 的 `s002_solver` 思路：原目标函数和活动范围，仅提高数值求解精度 |

**三组都是左臂固定关节 PD、右臂主动控制。左右指机器人自身左右，不能按正面画面的左右判断。**

选择 D03 的标准是姿态表现好、保留原控制结构、少引入真机最终未采用的功能，不是宣称全局最优。
之前的保守范围/加速度综合/姿态综合三个优化组合都引入了姿态预测校正和时间前视，部分还扩大关节活动范围；本次不将它们作为主展示。

D02 不是开环控制，也不是“取消所有前馈”：它仍然每 6 ms 用实测 q/dq 和当前身体扰动闭环重优化，并保留重力及原逆动力学执行。因此论文和画面使用 **No-Preview MPC**，不使用容易被误解的 “Open-Loop MPC”。
隔离适配器将当前扰动重复到全部 10 个节点和 9 个区间，D03 才使用未来模板值。
D03 的未来扰动是外生预览信号，并没有把未来扰动创新参数化成反馈策略。因此使用 **Disturbance-Preview MPC**，比 “Disturbance-Feedback MPC” 更符合当前实现。
适配器仍计算原模板并保留部分预测诊断，所以不能把 D02 的模板诊断字段当作该组优化器实际使用了模板预测的证据。

## 配置究竟改了什么

两组 MPC 的右臂目标函数、约束和预测结构均保持原仿真基线；右臂只调整了 OSQP 数值设置：

| 配置 | 原仿真基线 | D02 / D03 |
| --- | --- | --- |
| `mpc_osqp_eps_abs` | 1e-3 | 2e-4 |
| `mpc_osqp_eps_rel` | 1e-3 | 2e-4 |
| `mpc_osqp_max_iter` | 400 | 4000 |
| 线加速度/角加速度/角速度代价 | 0.01 / 0.0005 / 8 | 不变 |
| 端平代价 | [30,30] | 不变 |
| 回中代价 | [4,4,1.5,0.2,0.2] | 不变 |
| 控制周期 / 预测区间 | 6 ms / 9 | 不变，54 ms 窗口 |
| 姿态预测校正 / 区间前视 | 关闭 / 0 ms | 明确关闭 / 0 ms |
| MPC 速度 / 期望加速度上限 | 1 rad/s / 8 rad/s² | 不变 |

4000 是允许的最大迭代数，不是每拍必须执行的次数。第一次用历史 `s002_solver` 的 1500 上限时，D02 有一次迭代上限回退；因此**两组同时**提高到 4000。把左臂改为 `20/1` 后，D02 在 `1e-4` 容差下又出现少数达到迭代上限的拍；只把两组容差统一设为 `2e-4` 后，正式复跑均无 QP 失败。没有改代价、关节范围、力矩限制或预测结构。

`research_hold_future_disturbance` 是 D02 / D03 唯一配置差异（true / false）。`simple_controller` 只是隔离仿真入口的控制器选择标签。

MPC 扣除 margin 后的角度区间，顺序为肩 pitch、肩 roll、肩 yaw、肘 pitch、腕 roll：
`[-4,4]、[-4,2]、[-20,5]、[-40,40]、[-40,40]°`。没有采用优化组合里的 ±15° 肩 roll。

D01 保留原位置 PID 公式，仅修改三项配置：`kp=[1.2,1.2]→[0.12,0.12]`、`kd=[1.2,1.2]→[0.012,0.012]`、`pid_de_g_alpha=0.07→0.0215359257`。
积分增益 `ki=[0,0]`、回中增益、`pid_max_dq=0.48`、6 ms 周期、角度边界和底层 PD 均不变。导数滤波系数采用真机已有的 20 ms 参考滤波时间尺度，未增加前馈或动力学执行。
“PID”沿用仓库命名，原积分增益本来就是零。沿用该历史适配器的参考角裁剪区间：
`[-15,15]、[-15,15]、[-20,15]、[-40,40]、[-40,40]°`。
该参考范围比两组 MPC 宽；没有为了削弱 PID 而缩窄。PID 与 MPC 的参考/加速度限制不是同一种物理量，不能声称已证明各控制器最佳性能的严格排名。
配置里保留的 MPC 成本键不进入 D01 的 PID 控制律。原 D01 的完整配置和数据仍保留，可通过 D01_OLD 回放；新配置名为 `D01_position_pid_balanced.yaml`。此次调参不是将仿真 PID 宣称为真机 PID 的原样复现。

三组共同使用零中立位；左臂五个关节的名义增益统一为 `Kp=[20,20,20,20,20]`、`Kd=[1,1,1,1,1]`。腰部仍为 `100/15`，右臂底层执行增益仍为 `[80,80,60,80,30] / [5,5,3,2,1]`。腿部策略、初态、行走命令、物理模型和力矩限值保持一致。
这里的 `20/1` 是 MuJoCo 直接关节力矩 PD 的名义数值；它与 Arm SDK 中同名数字的闭环刚度不能直接视为完全相同。
腿部实际闭环轨迹会随手臂控制略有变化，不是强制完全相同的身体运动回放。

## 与真机相同和不同的部分

- 同类架构：6 ms、9 区间、关节 q/dq 状态、ddq 输入、多目标 MPC、逆动力学执行。
- 未增加真机最终未采用的姿态预测校正、时间对齐、状态外推、控制升频或更长窗口。
- 三组主展示使用与真机几何和质量一致的圆环负载：外径 65 mm、内径 25 mm、高 75 mm、质量 250 g；质心和抓取位置保持不变。旧 200 mm 模型及旧回放仍保留用于历史复现。
- 在统一左臂增益之前，曾做过只改变负载模型的隔离复跑：右臂线加速度相对旧模型分别变化 +0.46%、−0.14%、+0.39%，角加速度、线速度和角速度的变化均不超过 1.3%。这项历史检查支持直接使用真实圆柱动力学；当前表格则来自随后统一左臂 `20/1` 的完整复跑。
- 仿真使用历史任务扰动模板，真机使用 H0 学习预测器；两者数据、坐标处理、滤波和执行模型不同。
- 仿真角速度代价 8、真机 1 只在各自目标函数中解释，不能比较为八倍控制作用。
- 仿真保留 MuJoCo 正动力学候选检查；真机是带实测移动基座输入的耦合右臂五自由度动力学模型。
- 本批同步仿真按物理时间推进；主机计算慢不会自动成为电机延迟。本次不是硬件实时验收。

D01 的线加速度比 D02 略小，而 D02 两种倾角和角运动稍好，**不能声称这三组的每项指标都按 PID→无预测 MPC→预测 MPC 依次变好**。

## 左肩 roll Kp=50 的展示敏感性实验

为检查正面放大视角中左肩 roll 的可见运动，额外保留三组 `D01_R50`、`D02_R50`、`D03_R50`。它们只把左肩 roll 的名义 `Kp` 从 20 提高到 50；该关节 `Kd` 仍为 1，左臂其余四关节仍为 `20/1`。主展示 D01-D03 没有被覆盖。

以 D03 为例，左肩 roll 角度标准差从 1.451° 降到 0.674°，全程范围从 4.376° 降到 2.251°，所以肩关节本身在画面中确实少动约一半。但是左末端相对平均轴摆动 RMS 从 2.271° 增至 2.562°（+12.8%），角速度从 0.420 增至 0.439 rad/s（+4.3%）。更硬的关节减少了局部相对运动，也把更多身体摆动传给了末端。

同一轮 D03 右端的竖直倾角均值从 0.311° 变为 0.251°、摆动 RMS 从 0.187° 变为 0.181°；线加速度从 2.999 变为 3.011 m/s²。右端变化很小，主要结论来自左臂机械响应。

R50 的 D02/D03 为通过严格完整任务检查，使用更严格的 OSQP 数值设置（`eps=1e-4`、最大 8000 次、开启 polishing）；代价、约束和预测结构未改。三组 R50 均完整 PASS。该候选适合作为刚度敏感性展示，不能描述成与真机参数完全相同的主结果。

竖直倾角是每帧末端 +Z 与世界 +Z 的夹角的均值。平均轴摆动是每帧 +Z 相对于归一化平均轴的角距离 RMS，保留了方向信息。
原始轨迹、同定义全程/行走/停车分段指标见各 `D0*_metrics.json`；整表见 `metrics.csv`。
这些仿真加速度不能替代真机的离线重建、滤波后指标。
