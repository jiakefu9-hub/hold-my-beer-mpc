# 前馈 PID、位置 MPC 与加速度 MPC：2026-10-11 纯仿真对照

已实现并适量调参。核心结论：**前馈 PID 可以把姿态做得很好；加速度 MPC 的额外价值主要体现在受限运动中的线加速度与姿态折中，不能声称它在所有指标都优于 PID。** 当前强前馈 PID 的线加速度 2.988 m/s²，同范围的保守 MPC 为 2.762，上次加速度综合/姿态综合方案为 2.521 / 2.628。姿态综合 MPC 与强前馈 PID 的平均轴摆动几乎相同，但线加速度低 12.04%；强前馈 PID 的角速度和角加速度更低。

本轮 81 次启动尝试，62 次完整完成并导出，包含重复验证，不是 81 种控制器。19 次未完成导出中，18 次是新位置控制接入/导出兼容问题（均修复并重跑），1 次是过强加速度前馈 PID 触发原 `NO_SAFE_TORQUE` 检查。62 次完整导出中，2 次直接强化位置 MPC 加速度代价的试验姿态严重恶化，并发生 63 / 136 次求解回退，明确淘汰。没有放宽力矩限制或屏蔽控制失败来保留漂亮指标。

所有结果是本轮 MuJoCo 闭环实验，不是旧真机 PID，也不是硬件性能承诺。未连接机器人，未发送任何真实命令。原 MPC/PID 默认配置、真机入口及已有成功数据不改写。

## 控制器到底是什么

**原加速度 MPC**：状态 x=[q,dq]，共 10 维，输入是 5 维 ddq；ddq 不是第三个状态。滚动优化后经耦合逆动力学和 MuJoCo 候选力矩检查执行。

**A：位置输出前馈 PID**：利用实测瓶轴倾斜作 PID 反馈，并用模板预测的身体转动计算抵消量；经过阻尼伪逆得到关节速度参考，再积分为位置参考。最终版本还抑制瓶轴自转。它不是将未来真实 IMU 送入控制器，不需要力矩逆动力学。输出由与其余方案相同增益的底层 PD 跟踪。

**B：q-only 位置 MPC**：一个状态向量 q∈R⁵，不是一个标量。输入为位置参考 r∈R⁵，使用一阶位置伺服模型：

`q[k+1]=(1-beta)*q[k]+beta*r[k]+b`

其中 beta=0.2；b 来自上一拍模型预测和本拍实测 q 的差，按 0.2 增益低通更新，在本拍预测窗口内冻结。它是已知偏差修正，不是新的优化状态。只优化五个关节角及未来参考，不求逆动力学力矩。未来身体姿态进入端平代价，未来身体角速度进入角速度代价。9 个区间、54 ms 窗口，每 6 ms 执行首个位置参考。参考角、参考速度和参考加速度有界，物理状态仍会受底层伺服误差影响；不声称对未来真实关节角提供精确硬保证。

**C：同力矩执行层的前馈 PID（补充对照）**：二维倾斜 PID 形成任务角加速度目标，并对三轴末端角速度作阻尼；抵消预测的身体线/角加速度和移动基座项。用一次阻尼最小二乘解 5 个期望关节加速度，再使用与原 MPC 完全相同的力矩执行层。没有预测轨迹优化、没有 QP。它比单纯位置 PID 更复杂，但能回答“效果是否主要来自逆动力学，而不是 MPC”。其任务加速度关系采用当前局部运动学近似，并非完整非线性反馈线性化。

原仿真 PID 保持原增益，原 ki=0，控制名称沿用仓库；它不是本次新 PID 调参的最佳结果，也不能拿 9.4192 当作真机 PID 的加速度。A/B/C 由本次小范围探索选取代表点，不宣称各家族全局最优。C 是很有竞争力的对照，不能用弱 PID 的一行来回避它。

完整同轮左右臂数据见 [METRICS.md](METRICS.md)。不同右臂策略会通过全身耦合略微改变左臂，不能把左臂混成唯一不变的测量基准。竖直倾角为 `mean(acos(z_i·e_z))`；摆动为 `sqrt(mean(acos(z_i·normalize(sum z))²))`，不是无符号倾角的标准差。其余均为三维向量范数 RMS。线/角加速度沿用原记录的 2 ms 速度差分，没有另外平滑；首帧沿用原零值。

世界系线速度包含必需的向前行走速度，不以越低越好作为独立最优化结论。主要四个代表方案行走距离约 3.20～3.25 m，命令相同；无通过停止腿部运动取得优势。

## 比较要点与前馈消融

- 与 C 相比，同范围保守 MPC 的线加速度低 **7.58%**，但两项倾角、角加速度、角速度都未胜出。
- 与 C 相比，姿态综合 MPC 的线加速度低 **12.04%**；两项倾角分别 0.0632° 对 0.0581°、0.0742° 对 0.0733°，非常接近。MPC 角加速度反而高 **7.56%**、角速度高 **26.04%**。
- 加速度综合 MPC 对 C 的线加速度低 **15.62%**，但摆动 RMS 从 0.0733° 增至 0.1381°；不是所有指标支配。
- B 确实是 MPC，并非换名字的 PID；它优于 A 的倾角与角速度，但没有达到加速度 MPC 的动态综合水平。这个结论仅针对本次一阶伺服模型、代价与有限调参，不能证明所有位置 MPC 都不行。

## 实际参数与公平性

完整解析 YAML 位于 `configs/simulation_simple_controllers_20261011/`。`simple_*` 才是新控制器的代价/增益；配置中继承的 `mpc_q_*` 对新控制器不生效，保留这些字段只是使用统一预测/执行协议。

共同项：左右零中立位、正常固定左 PD、原底层 PD 增益、腿部策略、地面、初态、负载与物理 ±25 Nm 上限。A/B/C 与保守 MPC 采用同角度盒，扣除 margin 后依次为 pitch ±15°、roll ±15°、yaw [-20,15]°、肘/腕 ±40°；参考速度上限 2 rad/s、参考/期望关节加速度 15 rad/s²。A/B 约束参考变化，C/MPC 约束期望动力学输入，两者不等于实际加速度严格相同的硬限值。

共同提供因果模板前馈、姿态创新修正 gain=1 / decay=0.15 s、区间加速度前视 3 ms。A 使用预测角速度；B 使用未来节点姿态/角速度；C 主要用首个区间加速度。未来数据都来自已有冻结模板和当前反馈，无评估轨迹未来真实值。

## 面试可以怎么表述

“我做过位置前馈 PID、只以关节角为状态的位置 MPC，以及同逆动力学执行层的前馈 PID 对照。简单前馈 PID 已能取得很好的姿态，所以我不把姿态稳定完全归功于 MPC。相同运行范围下，MPC 将线加速度再降约 7.6%，但部分姿态与角运动指标不如前馈 PID。更宽运动范围的多目标 MPC 能在相近摆动幅度下进一步降低线加速度，代价是更多计算和更大的补偿运动。这些结果是仿真证据，还需要真机验证。”

保留三种新控制器与对应消融、原方案与强对照、失败记录，已经足够支持该比较，不建议为证明 MPC 必赢继续无限调参。实现与回放命令见 [工具说明](../../../../tools/experiments/simple_controller_comparison/README.md)。详细左右数据、所有尝试账本、来源哈希和配置见本目录；原轨迹保存在被 Git 忽略的 `evaluation/simple_controller_comparison_20261011/`，没有自动提交/推送。
