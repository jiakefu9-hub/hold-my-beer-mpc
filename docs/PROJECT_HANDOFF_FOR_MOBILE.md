## 三分钟掌握项目

- 平台是 Unitree G1 23DoF，每臂五个实际电机，腰一个实际关节。腿部由内置行走控制器负责，项目通过 `rt/arm_sdk` 控制手臂。
- 历史实验双手固定各约 250 g 水瓶；后期使用指示杆帮助展示方向。后期模型采用 75 mm 高、250 g 负载。模型尺寸、实际附件和录像外观是不同信息，不把模型参数冒充逐次实测。
- 主对照的左臂是固定零关节参考的 PD，正常增益五轴 `Kp=20, Kd=1`。它是闭环控制，不是“完全没有控制”，也不是机械锁死；关节实际会微动。
- 右臂主方案是 6 ms 加速度 MPC，九个预测区间，共 54 ms；利用身体 IMU、编码器和未来身体扰动，规划右臂五关节加速度，再经逆动力学转为力矩。
- 近期主实验双臂零中立位，使用 75 mm/250 g 模型；2026-10-08 `164546` 是保留的历史非零中立位成功基线。权重沿用不代表两轮其余条件完全相同。
- 真机评价坐标系为 H0：行走前稳定阶段平均 yaw 定义零方向，之后冻结。它不随身体转动，竖直方向保留；不是每一拍跟随身体旋转的局部系。
- 已完成位置 PID、学习预测消融 MPC、学习 MPC，以及 C 前馈加速度 PID 的比较；C 也已上真机，不能当作只有仿真结果。
- 当前最可靠的收益是竖直姿态和平均方向附近的摆动改善。末端线加速度没有普遍降低，落脚附近仍有短促振动；不能宣称液体晃动或杆尖振动已经消除。

## 控制结构必须讲准确

### MPC：状态是 q、dq，加速度是输入

右臂有五个关节，状态为 `x=[q,dq]`，共十维，控制输入为五维 `a=ddq`。不是“q、dq、ddq 三类状态”。每个预测区间使用二阶积分：

```text
q_next  = q + dt*dq + 0.5*dt²*a
dq_next = dq + dt*a
```

局部运动学模型将关节运动映射到末端重力方向误差、角速度、线/角加速度等任务量。因此虽然优化变量在关节空间，目标中有任务空间量；不能说它“完全不是任务空间控制”。代价还包含回中立位、关节速度和加速度正则，约束包含预测关节位置、速度、加速度和局部力矩包络等。

每拍用实测 `q/dq` 重新优化，只执行首拍，再滚动求解。优化的是整套加权目标，而非保证每项统计指标都同时变小。权重数值不能脱离模型、尺度、其他权重和执行方式，直接比较仿真与真机控制强弱。

真机保留的动态权重是 `q_ee_acc=0.01`、`q_ee_alpha=0.0005`、`q_ee_omega=1.0`。配置见[三代价基线](../configs/hardware_mpc_learned_acc001_alpha0005_omega1.yaml)和[力矩配置](../configs/hardware_mpc_torque_learned.yaml)。pitch/yaw 轻度回正在预测内；额外肩 roll 回正未保留。

### 执行层：带实测移动基座输入的耦合右臂五自由度模型

`tau_total=M(q)*a+b`，其中 `M` 是右臂耦合 5×5 惯性矩阵，`b` 包括重力、速度项和实测身体基座运动的作用。它保留右臂关节间耦合，但没有显式求解双腿、地面反力、完整浮动基座接触和内置行走控制器内部状态，不能称为完整全身动力学模型。

Arm SDK 同时有目标位置/速度、PD 增益和前馈力矩字段。程序在当前采样状态下扣除预期的固件 PD，再由固件加回，避免重复叠加：`tau_ff=tau_total-PD`。这不是“右臂没有 PD”，也不能认为仅改包内 Kd 就一定增加净阻尼。

仿真具备 MuJoCo 全模型状态，可以做正动力学候选力矩检查；真机没有完整且可信的接触状态，当前直接使用上述右臂模型及执行检查。模型内部闭合不等于已准确辨识实机摩擦、固件增益、执行延迟或外部接触。

### 三类对照各自回答什么

| 控制器 | 输出和优化 | 应如何称呼 |
|---|---|---|
| 左臂固定参考 PD | 固定零关节目标，由底层 PD 保持 | 同轮功能对照；没有世界系姿态反馈 |
| 位置 PID | 利用 IMU/运动学纠正姿态，产生受限的位置参考 | 传统位置参考控制对照；参考限速会影响收敛 |
| C 前馈加速度 PID | 姿态反馈给出任务角加速度，经单拍受约束最小二乘/QP分配五关节加速度，再用同一逆动力学执行层 | 强前馈对照，不是一个完全没有模型/约束/优化的简单 PID |

C 的单拍优化同时考虑姿态修正、线加速度和关节回中，包含下一拍 q/dq、ddq、总力矩、前馈力矩及既有制动限制。它没有 MPC 那样优化整段九区间的关节轨迹。两者都有约束，都不能据此保证无碰撞；约束与模型及状态估计有关。

真机 C 在部分角运动指标上优于 MPC，MPC 的两种姿态指标更好，线加速度没有可靠全面胜负。论文可以以 MPC 为主线、C 放在比较或补充章节，但不能省略 C 后宣称“简单方法不可能达到”。无需因发现强对照就重新开发整个项目。

## 预测、滤波和时间对齐

真机 `learned_filtered` 使用冻结的历史库，基于腿部 q/dq 与 H0 身体扰动特征查找相似状态，预测未来九个 6 ms 区间；在线不训练。时间戳用于因果网格、样本年龄、预测锚点和窗口对齐，不是简单“运行到第几秒就播放模板”。仿真完整任务模板与该真机库不是同一数据源或坐标处理。

`hold_current` 只消融学习预测，仍保留当前 IMU、重力、移动基座动力学补偿，**不能写成“关闭全部前馈”**。

真机身体扰动采用 2 ms 网格的 15 Hz 因果一阶低通。15 Hz 是截止频率，不是数据每秒只更新 15 次。角加速度由滤波角速度差分、再滤波得到。该链有频率相关滞后；关节状态和身体姿态不能一概当作经过相同滤波。

`--align-accel-forecast` 仅将未来区间线/角加速度取样向未来移动：查询相对网格锚点的年龄约 0～2 ms，加 3.5 ms 主机写出预算，总计约 3.5～5.5 ms。区间重叠加权，最后不足的预测时间沿用末段均值。它不外推当前 q/dq，不修改当前逆动力学输入，不反演 15 Hz 滤波器，也没有识别完整电机延迟。

离线预测误差改善不等于末端效果改善；最终主 MPC 关闭对齐，C 保留开启，是现有证据下的工程选型。仿真新增的姿态预测误差校正未直接放进真机主方案。仿真 4 ms C 候选也没有自动升级为真机 4 ms。

离线指标的 105 ms Savitzky–Golay 窗口是运行结束后的数据处理，不在在线控制回路中，不能计为额外 105 ms 控制延迟。

## 论文结论应以这些证据为中心

2026-10-13 上午三种控制器各两轮，统一 `[5,18)` 完整走停窗口，右端结果如下。按每轮指标再平均，不把每个时间采样当成独立重复实验。

| 右臂方案 | 竖直倾角均值 ° | 相对平均轴摆动 RMS ° | 三维线加速度 RMS m/s² |
|---|---:|---:|---:|
| 位置 PID | 2.3550 | 2.9576 | 1.8649 |
| 当前扰动保持 MPC | 0.6263 | 0.5742 | 2.1178 |
| 学习 MPC | 0.6308 | 0.5819 | 2.0938 |

学习预测的新增收益远小于 MPC 相对位置 PID 的姿态差距。不能用 MPC 对 PID 的全部改善作为学习模块的贡献；也不能说本批 MPC 线加速度低于位置 PID。

最新分段分析：起步 `[5,7)`、中途 `[7,15)`、停车减速与稳定 `[15,18)`。学习 MPC 的左/右摆动 RMS 在中途是 `0.6346°/0.5178°`，停车为 `1.8519°/0.6215°`。右相对左的优势从约 18.4% 增到 66.4%；右手本身停车摆动略大于中途，不是“所有停车时刻绝对更稳”。无学习 MPC 也有明显停车姿态优势。

原位置 PID 起步仍在纠偏，其完整窗口摆动包含初始收敛。后半段单独分析仍有姿态差距，但不能把完整窗口结果全部叫稳态振荡。放宽参考限速的 PID 录像单独保留，不混入原 PID 重复组。

关键量定义：

- 竖直倾角：每帧末端 +Z 与 H0 向上的夹角，再取均值或 RMS，必须注明是哪一个。
- 平均轴摆动：先归一化平均轴方向，再取每帧轴与平均轴的角距离 RMS；不是无符号竖直倾角标量的标准差，也不包括绕瓶轴自转。
- 线/角加速度与角速度：三维向量模 RMS，非只看某个方向；原始重建和滤波方法要注明。
- 当前速度口径：末端相对 torso IMU 的位置导数，再去窗口均值，非世界系绝对平移速度。
- 末端指标主要由 IMU、编码器和运动学重建，并非瓶子或杆子上的独立传感器真值；“角加速度”不要误写成“脚部加速度”。

不能省略的局限：重复次数少、身体激励有轮间差异、固定零位 PD 与主动控制的平均姿态不同、可能有接触、杆安装松动和柔性振动不在刚体模型内。T05 录像观察到上臂/躯干接触，仍保留为实际运行对照并标注；不能称其确认无接触。人为左臂扰动或增益加倍运行不能混入正常左 PD 主对比。

论文聚焦起停是实验后的研究范围收敛，应说明分段方法并保留完整任务和持续行走结果；仿真放大视频标明是仿真及播放尺度，不能替代真机证据。
