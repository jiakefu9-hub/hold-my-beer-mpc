# H0 扰动预测：误差百分比与进一步改进

2026-09-25，接[第一轮十二条研究](H0_WALK_PREDICTOR_STUDY.md)。全部离线；没有修改机器人控制程序或连接机器人。

## 1. 0.413／0.442／0.473 到底有多好

这是全下肢角度＋角速度查表的 **H0、15 Hz 因果滤波后三轴线加速度分量 RMSE**，单位 m/s²。
覆盖起步、行走、停车／平衡段。百分比必须说明与谁比，公式是：

`误差降低百分比 = (对照误差 − 本方法误差) / 对照误差 × 100%`

| 未来区间终点 | 沿用当前测量 | 原全腿查表 | 相对沿用当前值 |
| --- | ---: | ---: | ---: |
| 6 ms | 0.3070 | 0.4133 | **变差 34.6%** |
| 24 ms | 1.3527 | 0.4421 | **误差减少 67.3%** |
| 54 ms | 1.6538 | 0.4732 | **误差减少 71.4%** |

所以中远期是有价值的改善，但它不适合独占最近一格。这不是“预测正确率 71%”，也不是稳杯性能提升 71%。
误差仍不算接近零：此批真实滤波加速度的三轴波动尺度约 1.29 m/s²，0.44 大约是它的三分之一。

## 2. 本轮实际试了什么

保持相同 H0、预处理、九个 6 ms 提前量、左端区间标签和预测时刻；旧五条仍不参与。
依旧用开发 01–05／07／08 选参数，06 单独隔离，09–12 只比较。
**09–12 上轮已看过，所以这轮叫探索性复查，不能重新包装成全新盲测。**

- 增加当前 IMU 的邻居检索：不只看腿，还看身体此刻的加速度、角速度和角加速度。
- 改为预测变化量：`现在的测量 + 历史相似时刻之后的变化`。
- 邻居附近拟合小型局部线性模型，替代直接加权平均。
- 非线性腿部特征＋近期 IMU／腿历史：固定随机种子的余弦特征，学习未来相对当前的变化。
  这种特征映射有[核近似方法依据](https://scikit-learn.org/stable/modules/kernel_approximation.html)，本轮用 NumPy 自行实现，没有安装新库。
- 用开发集预测误差确定连续混合权重，代替硬切换。
- 最后做当前 IMU 偏差修正，并约束修正量随着预测时间变远而减弱。

局部方法六个固定配置、非线性方法六个固定配置，均先记录配置，再做七轮整条留一验证。
混合／衰减权重使用开发集留一预测拟合；这个权重拟合自身**不再冒充额外独立交叉验证**。
所有候选，包括没有改善的，都保存了模型、逐点预测、误差和参数选择记录。

### 代表性结果

同样的四条比较轨迹、全主窗口，加速度 RMSE：

| 方法 | 6 ms | 24 ms | 54 ms |
| --- | ---: | ---: | ---: |
| 上轮近远期组合 | 0.2468 | 0.4421 | 0.4732 |
| 加当前 IMU，直接查未来值 | 0.3509 | 0.4291 | 0.4743 |
| 加当前 IMU，查未来变化量 | 0.2064 | 0.5398 | 0.6013 |
| 邻居局部线性，k64／ridge0.1 | 0.4075 | 0.4474 | 0.5159 |
| 开发集选中的非线性历史模型 | 0.2061 | 0.5122 | 0.6602 |
| 原两模型按开发集连续混合 | 0.2396 | 0.4423 | 0.4734 |
| **历史未来趋势＋逐渐衰减的当前偏差修正** | **0.1941** | **0.4278** | **0.4743** |

非线性模型的综合交叉验证分数较好，并不代表表中每个加速度提前量都更好：原综合指标还包括角速度、角加速度。
不能只选一个较好综合分数，隐藏远期加速度退化。

## 3. 最有用的新思路：先信历史趋势，再用当前测量修正

可以这样理解：历史库说当前这样的腿和身体状态，接下来通常会产生某条扰动曲线；但今天这一瞬间
的实际 IMU 和历史邻居的 IMU 有一点偏差。这个偏差对紧接着的几毫秒很有用，但不该原封不动地带到很远处。

具体保存的公式：

`预测 = 历史邻居的未来值 + λ(h) × [当前 IMU − 历史邻居的当前值]`

邻居搜索同时用十二腿关节 q/dq 和当前三类 IMU 运动量。两个基础模型使用同样标准化、k=8 和邻居权重；
代码已检查括号中修正项在施加衰减前不随预测提前量变化。
每个物理量组各有九个 λ；仅用开发集留一预测最小化平方误差，要求：

`1 ≥ λ(6) ≥ λ(12) ≥ … ≥ λ(54) ≥ 0`

本轮加速度的 λ 约为：6 ms **0.821**、12 ms **0.374**、18 ms **0.166**、24 ms **0.089**、54 ms **0.004**。
这不是手工给比较集调的参数。说明数据本身支持“越近越利用当前偏差，越远越靠历史规律”。
姿态沿用变化量模型，没有把上述运动量权重直接套给姿态；正式接口仍要处理 SO(3) 与角速度一致性。

相对上轮已经较好的组合，新方案：

- 最近 6 ms：0.2468 → 0.1941，**再减少 21.4%**。
- 24 ms：0.4421 → 0.4278，**再减少 3.2%**。
- 54 ms：0.4732 → 0.4743，约变差 0.2%，**可视为尚未发现改善，不是新的突破**。

近 6 ms 四条分别改善约 23.7%、20.5%、21.0%、20.5%；24 ms 四条分别改善 4.3%、4.0%、1.5%、3.2%。
起步／稳态／停车段的 6 ms 误差分别为 0.2104／0.1796／0.2187，均低于原组合。
54 ms 有的条略好、有的略差。只有四条同日比较，3.2% 的中期收益尚需新轨迹确认。

## 4. 没有解决什么

这些不是原始冲击的同等改善。新方案相对**未滤波**加速度区间的误差为 1.3896／1.4229／1.4607 m/s²。
最近 6 ms 相对沿用原始读数的 1.4425 只改善约 **3.7%**，其中可能包括去噪收益，不能归结为已精确预测原始冲击。

这一轮没有证明 54 ms 加速度误差能大幅继续下降，也没有证明更复杂模型必然有效。
但同批数据上的失败不等于理论上已到极限。未观测的接触变化、IMU／关节的相对时延、噪声和手臂动作变化
都可能影响预测；它们仍是后续排查方向，不是本轮已确定的误差来源。

## 5. 建议下一步

先把**逐渐衰减的当前偏差修正**作为近端增强候选保留，远期继续保留原全腿查表作对照，不直接覆盖 MPC。
不要为了让已看过的四条数字继续变小而无限扩展选参。

下一轮最有价值的是：

1. 冻结这次程序，用新日期、同条件完整轨迹检验收益能否保留，尤其是只有 3.2% 的中期变化。
2. 明确 MPC 要用哪一种扰动估计。若要补偿原始冲击，直接按那个目标训练／验证，而不是继续优化滤波目标再声称物理效果。
3. 对最大误差窗口区分“峰值幅度不对”和“发生时间没对齐”，再决定补采接触相关信息或改同步，而非盲目换更大网络。
4. 通过只读在线回放／shadow 记录实际时序、计算时间和超出训练分布的情况，之后才讨论闭环前馈。

程序仍集中在 [`tools/g1_commissioning/walk_h0_study/`](../../tools/g1_commissioning/walk_h0_study/README.md)：
