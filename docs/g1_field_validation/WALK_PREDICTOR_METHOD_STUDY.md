# 真机扰动预测：方法解释、实测比较与下一步选择

2026-09-18。使用 9 月 17 日五条带瓶、防跌保护行走轨迹；本轮仅离线研究，没有连接机器人、改控制入口或导出部署模型。

## 结论先行

**用户提出“加入下肢角度等信息”是对的，且这五条数据已经支持这样做。**
但没有一个万能的膝关节角度，也没有证据说明任何一篇最新论文的方法必然最好。
现在值得推进的主线是：**根据当前／最近的腿部角度和速度，加上近期身体 IMU，预测未来短时间的扰动**；
把旧的相位均值保留为对照，不把它直接定为最终方案。

本次比较中：

- 最近 6 ms：带正则的“IMU＋腿部短历史”线性预测更好，适合作为简单基线。
- 24–54 ms：按腿部状态寻找历史相似片段的非线性查表更好，值得作为“状态索引的扰动模板库”候选。
- 不能据此立即拼成控制器：尚需新的整条轨迹验证、完整 6 ms 间隔预测、姿态一致性、滤波／通信延迟和执行时间评估。

“更好的扰动预测有助于 MPC”成立，但预测误差降低百分比不等于稳杯效果提高百分比。
时序、世界系定义、动力学误差、执行器约束、手臂动作对机身的反作用也会影响结果。

## 1. 模板到底以什么为横轴

可以有两种不同的东西，不必强行都画成一条 X–Y 曲线：

**一维相位模板**：X 是一个周期走到百分之几，Y 是该阶段通常出现的扰动。
它不是“程序开始后第几秒”。没有读到官方 `GetPhase`，仍可以从腿部运动估计一个用于预测的相位；
无需证明它就是内置强化学习策略的内部 phase。

**多变量条件预测**：X 是一组状态，而不是单独一个数。例如：

```text
输入 = 最近 120 ms 内若干时刻的：
       腿部关节角 q、关节角速度 dq、身体 IMU／派生量
       ＋ 要预测多远 h
输出 = 未来 h 附近的世界系线加速度、角速度、角加速度、姿态
```

本轮历史抽取时刻是现在、12、30、60、120 ms 前，共五个点，不是把未来腿角输入模型。
以后还可加入当前已知的速度请求／是否已请求停车、相位估计及置信度；这些是候选，不是本轮已全部实现的特征。
时间仍用于历史顺序、提前量和起停阶段，但不必把“第几秒”当唯一索引。

这里“四项扰动”是四类量：`a_W、omega_W、alpha_W、R_WB`。
前面三类各三轴，姿态应是旋转矩阵／四元数；角加速度需要估计，并非额外读到的独立 IMU 通道。
本轮 RPY 只做姿态诊断，尚不是物理一致的姿态预测接口。

## 2. 上次 38%／51% 是怎么得到的

旧程序 [`analyze_walk_dataset.py`](../../tools/g1_commissioning/analyze_walk_dataset.py) 的做法：

1. 左髋 pitch 减右髋 pitch，因果 10 Hz 低通。
2. 用带滞回的正向过零标记一次周期；它是腿部运动事件，不是力传感器确认的触地。
3. **前三条**完整周期分别缩放成 128 个相位点，把每个点的世界系扰动平均。
4. 在**后两条**预测时，只用已经发生的事件；过去最多三个完整周期的中位数估计周期长度。
5. 根据当前距上次事件多久、再加预测提前量，读取模板未来相位的值。

因此旧方法已经使用下肢信息，只是把它压缩成了一个相位，没有充分利用多关节和近期 IMU。

38%／51% 专指**稳态段、因果 15 Hz 滤波后的世界三轴线加速度、未来 6 ms 区间近似均值**的 RMSE：

| 预测目标区间 | 沿用当前测量 | 纯相位均值 | RMSE 降低 |
| --- | ---: | ---: | ---: |
| 未来 18–24 ms | 1.352 m/s² | 0.835 m/s² | `1−0.835/1.352 ≈ 38%` |
| 未来 48–54 ms | 1.699 m/s² | 0.839 m/s² | `1−0.839/1.699 ≈ 51%` |

不是四类量全部提高这么多，不是原始落地冲击已精准预测，也不是闭环稳杯提升这么多。
完整周期终点仅用于训练／事后画图对齐；检验预测没有用未来事件终点。
这是合理的最初对照，但上次没有据此完成最终模板。

## 3. 你的数据里，哪些关节确实有关联

先在前三条找跨轨迹符号一致的关系，再在后两条检查。下表输入是现在的状态，输出是 **24 ms 后**的量：

| 现在读到的量 | 未来的量 | 第 4／5 条相关系数 |
| --- | --- | ---: |
| 左右膝角度差 | 身体 roll | +0.952 / +0.953 |
| 左右膝角速度差 | 世界 X 角速度 | +0.721 / +0.720 |
| 左右髋 pitch 角度之和 | 世界 X 线加速度 | −0.666 / −0.666 |
| 左踝 roll 角度 | 世界 Y 线加速度 | −0.760 / −0.764 |
| 左右髋 pitch 角度差 | 世界 Z 角速度 | +0.867 / +0.907 |
| **单独左膝角度** | **世界 Z 线加速度** | **−0.096 / −0.092** |

这说明“不同分量需要不同信息”，不是膝角度能解释全部冲击。
相关系数接近零也不代表没有非线性关系；同一膝角会出现在屈曲、伸展和长支撑平台上，
加上速度／历史才更容易区分。所有量也可能只是共同跟随步态，相关不证明谁引起谁。

具体相关图、领先时间曲线及膝角屈伸分支见[关联检查](../../evaluation/hardware_shadow/commissioning/walk_predictor_study_20260918/associations/README.md)。
该检查用未额外滤波的 q/dq 和滤后 IMU 做点值相关；下面预测比较对 q/dq 也用 15 Hz 因果低通，
acc／alpha 按区间评分。两张表的统计口径不能混用。

## 4. 这次实际比较了哪些方法

没有安装新学习框架。使用当前 NumPy／SciPy，测试两类简单模型及输入组合：

- **带正则的线性回归（ridge）**：从现在和过去若干状态直接预测各提前量，避免参数过度追着噪声走。
  有 IMU 历史时可理解为 ARX 风格的多变量预测，但不是已经辨识了“腿关节导致 IMU”的因果动力学。
- **相似状态查表（kNN）**：在前三条的状态中找相近点，把那些时刻随后 6／24／54 ms 的扰动加权平均。
  本次选出 8 个近邻（纯膝角模型选 24 个）；邻点可能来自同一周期的相邻帧，不等于 8 次独立实验。
  它仍是一种模板思想，只是索引从“一维相位”换成了“多维状态”。

输入逐项比较：双膝角；双膝角＋任务时间三次多项式；双膝 q/dq；全部下肢 q/dq；
下肢短历史；IMU 短历史；两者短历史合并；IMU 历史加相位谐波。

### 如何避免用答案预测答案

- 前三条内部按整条轨迹轮流留一条，选择 ridge 正则强度／kNN 邻点数；每一折的标准化也只用训练两条。
- 所有输入取当前及过去，按收到消息的时间配对。没有随机拆散相邻帧，也没有用未来关节、未来峰值或未来周期终点做输入。
- 之后用前三条重新拟合，在后两条比较。**后两条上一轮已查看，本轮属于探索性比较，不再称全新盲测。**
- 一次走路里的成千上万点高度相关；有效独立条件仍只有五次同日行走，不输出虚假的“大样本显著性”。
- 主要比较 7–14.7 秒稳态；额外拟合 5–17.9 秒起步—稳态—停车窗口，分别评分，不声称覆盖整个 0–21 秒升退权过程。

### 主结果：确实存在比旧模板更好的候选

下表同样是后两条合并的三轴线加速度区间 RMSE，单位 m/s²，越低越好；数值已复现旧基线。

| 方法 | 未来 0–6 ms | 未来 18–24 ms | 未来 48–54 ms |
| --- | ---: | ---: | ---: |
| 沿用当前测量 | 0.544 | 1.352 | 1.699 |
| 旧相位均值 | 0.833 | 0.835 | 0.839 |
| 只看双膝角，线性 | 1.135 | 1.131 | 1.143 |
| 双膝角＋任务时间，线性 | 1.134 | 1.131 | 1.143 |
| 双膝角，非线性查表 | 0.903 | 0.994 | 0.947 |
| 双膝角＋角速度，非线性查表 | 0.525 | 0.529 | 0.530 |
| 只看近期 IMU，线性 | 0.472 | 0.873 | 0.992 |
| **近期 IMU＋下肢历史，线性** | **0.376** | 0.617 | 0.783 |
| **当前全部下肢 q/dq，非线性查表** | 0.462 | **0.481** | **0.504** |
| IMU＋下肢历史，非线性查表 | 0.428 | 0.468 | 0.515 |

可以得到比“找相关系数最大的一项”更强的结论：

1. **给膝角再加程序时间，并没有明显帮助**，至少这个简单多项式时间模型如此；不是证明所有时间模型无用。
2. 双膝角的查表加入运动速度后，24 ms 误差从 0.994 降到 0.529，说明运动方向／状态很重要。
3. 同为线性模型，IMU-only 加入下肢短历史后，三个提前量误差都下降，证明腿部带来超出近期 IMU 的增量信息。
4. 更多输入不一定总更好：54 ms 时，简单 24 维下肢 q/dq 查表略优于 180 维 IMU＋下肢历史查表。
5. 第一条起步相位相反仍参与训练，不靠丢掉它制造重复性；另两条均有中远期收益，不是只靠其中一条。

其他物理量也检查了。例如 24 ms 的世界角速度 RMSE：当前测量 0.0914、旧相位 0.0697、
IMU＋腿部历史线性 0.0289、下肢查表 0.0308 rad/s。
同提前量角加速度区间 RMSE 分别为 4.445、2.753、1.471、1.236 rad/s²。
详细逐轴误差、每条误差、分量误差 p95 均在 `benchmark/metrics.json`，不只保留平均分。

又用前三条确定的高加速度阈值约 2.987 m/s² 单独检查困难片段：24 ms 加速度 RMSE
由当前测量 3.134、相位模板 1.935，降到下肢查表 1.024 m/s²；不是仅在平缓区间改善。
但这仍是**滤后的大加速度片段，不是独立标记的触地事件**；阈值用未来真值仅用于评分，不进入预测。

### 起步／停车：为什么仍不能宣布查表全程最好

补充模型把 5–17.9 秒一起训练，在起步／停车窗口的三轴加速度误差如下：

| 阶段／提前量 | 沿用当前值 | IMU＋腿部历史线性 | 同输入非线性查表 |
| --- | ---: | ---: | ---: |
| 起步，6 ms | 0.550 | 0.431 | 0.580 |
| 停车，6 ms | 0.504 | 0.456 | 0.624 |
| 起步，24 ms | 1.409 | 0.896 | 0.649 |
| 停车，24 ms | 1.375 | 0.934 | 0.681 |

查表的中远期收益并不保证最近一步也好。过去状态很相像，是否刚请求停车仍可能不同；
本轮模型没有输入速度请求和起停状态，这是下一版值得添加的已知信息，不是再加无数关节的理由。
第一种起步相位仍只有一条，吊绳拖拽也未量化。

### 数字的边界

所有候选用相同因果滤波、节点／区间定义；加速度为旋转到世界后扣重力，未悄悄去静态偏置。
角加速度由滤后角速度差分再滤波。区间均值用三个 2 ms 右端点近似，不是精确连续积分。
滤波有滞后，**预测滤后量不等于精确预测原始接触冲击**；真实输出延迟、滤波延迟补偿和闭环收益都未由本轮证明。
RPY 只是小角度诊断，最终必须保证 R／omega／alpha 的一致性。

训练内部评分是三类向量×三个提前量的 `MSE/ZOH_MSE` 平均；最低约 0.187 来自 IMU＋下肢历史线性模型，
这不是“综合 RMSE 改善 81.3%”，也不能据此否认查表在较远提前量的优势。
旧相位／按秒均值未参与同一套超参数 CV，不宣称线性模型赢得了所有方法的统一交叉验证。

## 5. 工程与论文中有哪些路线

下面区分文献支持与本机证据，不把人类步态或模型车结果直接当作 G1 验收。

| 路线 | 可靠资料支持的内容 | 对当前项目的判断 |
| --- | --- | --- |
| 角度＋角速度估相位 | [Choi 等，2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10575403/)用大腿角与角速度相图在线估计步态相位，并处理滤波滞后；对象为可穿戴系统 | 无官方 phase 也可估计；本机 q/dq 消融支持运动方向重要，但不等于该论文算法已在 G1 验证 |
| 自适应振荡器 | [Righetti 等，2006](https://infoscience.epfl.ch/server/api/core/bitstreams/5b1fe518-a0f8-44b2-bc8b-639bfeb881fa/content)从周期／准周期输入在线学习频率 | 可升级简单过零法；起停、谐波混淆、锁定置信度仍需检验，本轮未实现它 |
| 历史多变量回归 | [MathWorks 官方 ARX](https://www.mathworks.com/help/ident/ref/arx.html)支持历史输出、多输入、延迟和正则化估计 | 成熟工程基线。本轮为直接多提前量的 ARX 风格 ridge，不是照搬某个 ARX 递推模型 |
| 局部数据模型／GP | [Hewing 等，TCST 2020](https://arxiv.org/abs/1705.10702)用名义模型＋高斯过程学习和不确定性辅助 MPC | GP／核回归适合作为非线性候选；本轮实际只试了相似状态查表，不能宣称 GP 在本机更好。完整 GP 的计算与不确定性校准还需评估 |
| 近期腿式机器人残差学习 | [Zhou 等，2025 预印本／RA-L 工作](https://arxiv.org/abs/2510.15626)用随机傅里叶特征和在线最小二乘学习 MPC 残差 | 支持轻量非线性模型的方向；作者报告的是 Gazebo／MuJoCo 四足仿真，不是本台 G1 的实测证据 |
| 接触模式估计 | [Menner、Berntorp，2024](https://arxiv.org/html/2404.03444v1)用切换模型联合估计状态与接触，并在 Unitree A1 验证 | 比简单膝角判触地更有物理依据，但不是 G1，也不是未来 IMU 预测；当前不必扩大成接触动力学重构 |
| 近期时间序列基础模型 | [Chronos-2，2025](https://arxiv.org/abs/2510.15821)支持多变量、协变量和零样本预测 | 先进但没有本台 G1、这个数据量与 6 ms 控制约束下的优胜证据，本轮未安装／测试。论文新不等于此处最合适 |

检索还包括 2026-09-14 的新预印本 [Ryu、Hur：个体化步态相位估计](https://arxiv.org/abs/2609.14984)：
比较了 LSTM、TCN、Transformer，并报告个体适配和嵌入式计时。
它使用预训练模型和脚跟压力传感器标签、研究人类外骨骼步态，并不是从五条无接触标签 G1 轨迹直接获得精准扰动预测。
这类近期研究值得借鉴历史窗口、多通道与个体适配，但不能据此认定我们应马上换 Transformer。

因此不能说“最前沿的一定最好”。这批数据更支持先做可解释、轻量的状态条件预测；
只有它在新数据上的剩余误差确实需要更复杂模型，才增加核模型、小网络或其他方法。
目前没有找到可以直接套用并声称已验证“这台 G1、只有这五条轨迹、全部四类扰动、6 ms 真机闭环”的文献结论。

## 6. 建议下一步怎么实现，不在本轮直接做完

**推荐方向：状态索引的扰动库＋近期测量修正；相位作辅助而不是唯一钥匙。**
这是候选结构，不是已经验证完成的混合控制器。

交给后续实现时，范围可以限定为：

1. 复用本轮因果预处理和整条轨迹划分，固定 W 系语义；保留 ZOH、旧相位均值作对照。
2. 先实现两个轻量候选：IMU＋腿部短历史 ridge；全部下肢 q/dq 的相似状态扰动库。
   已有离线脚本足够起步，不先上大型训练系统。
3. 给出 6、12……54 ms 的完整预测区间，而不是只支持本次三个检查点；当前节点用真实测量。
   姿态按旋转处理，并检查与 omega／alpha 的一致性。近远期如何组合要再验证，不直接按本表生硬切换。
4. 加入当前已知的起步／停车请求和模式；相似状态太远、记录过时或不确定时回退实时测量，不能在库外强行外推。
5. 评估逐轴误差、冲击窗口、起步／停车、计算尾延迟和时间对齐；本轮批处理计算速度不是 6 ms 在线实时保证。
6. 方法确定后采新的 3–5 条作首次独立检验；不要继续用已经多次查看的第 4／5 条宣布最终成功。
   后续改变瓶子、上肢控制方式或防跌拖拽条件，还应检查分布是否变化。

本轮到“选路线和比较证据”为止，未增加 MPC 输出、未修改真实实验安全门、未提交／推送。
