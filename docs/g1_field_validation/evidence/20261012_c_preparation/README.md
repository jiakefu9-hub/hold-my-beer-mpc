# C 首次现场候选的离线验收

2026-10-12早期准备记录，使用原±15°正常roll范围及1.5 s过渡。
本目录没有真机新实验；其通过结果不能替代随后收紧边界后的验收。最终参数为任务 Kp/Ki/Kd=400/50/40、线加速度权重0.4、
正则0.012、关节回中24/8；配置副本及哈希与回放一致。原 MPC 配置未改写。

- `summary.json`：紧凑汇总。75项现场相关回归测试、7项仿真控制器测试通过。
- `replay_summary.json`：两个完整历史输入回放，含源码/配置哈希、预检与实际控制器标识。
  网络 socket 被禁止，未初始化 DDS；2448/2440个活跃命令，均完整退权到0。
  其中主要计算窗口2165/2157拍，全计算均值2.308/2.202 ms，p99为2.786/2.511 ms，
  最大3.149/2.898 ms，超过6 ms均为0。包含预测、控制计划和序列化，不含真实网络写出和电机响应。
- `conditional_model.json`：两条历史身体输入 × 0/4 ms，四例在3.3～4.8 s接入后完整运行至18 s。
  虚拟手臂响应C指令，但模型未辨识，无真实接触、传感噪声或手臂对身体的反作用。
  这不是4次真机验证，也不是模拟完整行走接触环境。
- `baseline_parity.json`：与保存的原运行时200拍对照，未选C时输出最大绝对差为0。
- `rejected_relaxed_*`：更软150/25参数在一例条件模型中触及yaw边界，未选作现场候选。
- `field_tests.txt`、`simulation_tests.txt`：测试原始输出。

完整机器人仿真及接触审计另见
[C研究报告](../../../simulation/experiments/20261012_c_refinement/REPORT.md)。

不是用旧机器人运动证明新C效果。
