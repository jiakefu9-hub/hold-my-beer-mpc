# T 系列整理后的离线证据

本目录对应2026-10-12收紧roll边界、接管过渡1.2 s后的版本。
没有连接机器人、初始化DDS或发送真实指令。

- `summary.json`：4个不同配置的预检、16组条件模型检查和最终配置哈希。
- `final_*_model.json`：T01/T02/T03/T06各两条身体输入×0/4 ms延迟。
  `final_mpc_model.json`对应T02，在验证脚本改名之前以`--baseline`选择；数值路径相同。
- `mpc_bounds3_model.json`：仅收紧外边界到+3°、仍用旧1.5 s过渡的失败证据。
- `c_bounds_model.json`：早期外边界+2°方案在一条输入下失败，未采用。
- `field_tests_final.txt` / `simulation_tests_final.txt`：112/36项通过。
- `baseline_parity.json`：2个准备样本与200个控制样本，旧MPC命令差异为0；
  只为比较数学路径，使用0.1 s求解预算，不是实时性能测试。
- `preserved_baselines.json`：五个原基线文件与整理前HEAD逐字节一致。

条件模型中的右臂会响应命令，但它使用控制器自身的模型；不包含真实执行器误差、
噪声、手臂对身体的反作用或全身接触动力学。采样接触检查把其他关节固定在qpos0，
只能说明这些采样姿态没有检测到接触，不能证明整个角度范围或实际机器人不碰撞。
检查止于18 s停车段末；退权和进程故障后的零权重由独立回归测试覆盖。
旧日志roll超过新外边界，因此历史输入回放标记不适用，未将其列作完整回放通过。

完整实验命令和限制见[实验单](../../sessions/20261012_MPC_C_COMPARISON.md)。
原始日志与整理前快照仍在被Git忽略的`evaluation/`，本目录不能替代原始数据备份。
