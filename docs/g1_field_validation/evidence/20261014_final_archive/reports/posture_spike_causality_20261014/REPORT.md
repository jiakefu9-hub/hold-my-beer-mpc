# 学习 MPC 落脚冲击与姿态保持动作的因果检查

本检查只读取五轮既有真机日志，并做固定实测状态回放和纯仿真；没有连接机器人或发送指令，也没有修改真机控制器和成功配置。

## 结论

用户提出的机制**部分正确，而且是重要原因之一**：落脚冲击改变身体姿态和速度，MPC 为保持右末端世界竖直，会迅速改变关节加速度和力矩。当前 `q_gravity=[30,30]` 是这类动作中最强的单项驱动因素。

但不能把全部右手振动概括为“左手先偏了，右手再纠偏”：

1. MPC 不读取左手偏角；它根据右臂实测 q/dq、身体 IMU 和未来扰动预测控制右臂。左手只是对照。
2. 左手绝对倾角大，主要来自零关节中立位的几何偏置。冲击造成的短时增量并不稳定地大于右手。
3. 一些最大加速度/力矩翻转发生在右端倾角已经很小或正在减小时，属于抑制角速度、角加速度和移动基座扰动的制动动作。
4. 逆动力学中的身体线/角加速度补偿 `b` 也会直接造成力矩突变；并非所有尖峰都来自 MPC 的姿态误差反馈。

## 五轮真机事件对齐

用原始身体 IMU 线加速度模长峰作为落脚冲击代理，不把它冒充脚接触真值。共得到 98 个有效事件。每个事件以冲击前 `[-30,-12] ms` 的瓶轴倾角中位数为局部基准，检查冲击后 `[0,60] ms`。

| 指标 | 中位数 | P90 |
|---|---:|---:|
| 左端冲击前绝对竖直倾角 | 13.17° | 13.65° |
| 右端冲击前绝对竖直倾角 | 0.60° | 0.93° |
| 左端冲击后的最大倾角变化 | 0.296° | 0.696° |
| 右端冲击后的最大倾角变化 | 0.354° | 0.575° |
| 左端变化峰相对冲击时间 | +48.0 ms | +59.5 ms |
| 右端变化峰相对冲击时间 | +24.0 ms | +56.7 ms |
| 右臂期望关节加速度模长峰 | +33.3 ms | +46.1 ms |
| 总力矩相邻拍变化峰 | +20.5 ms | +51.1 ms |

右端短时倾角变化只在 46.9% 的事件中小于左端，所以不存在“每次落脚左端先出现更大角度偏移、右端只是把它压住”的统一时序。总力矩变化峰约一半出现在右端倾角峰之前；期望关节加速度峰约 41% 出现在右端倾角峰之前。说明控制包含提前/同步补偿，也包含冲击后的纠偏和制动。

最新 12:53:33 一轮的首个强冲击更接近用户描述：`t=5.5356 s` 时身体冲击代理为 22.23 m/s²；右端冲击前倾角约 1.11°，随后变化 0.419°；总力矩变化峰在 +2.9 ms，期望关节加速度模长峰和右端倾角变化峰都在 +14.9 ms。这个事件中姿态保持明显参与了大动作。

## 相同实测状态下的代价消融

以最新 12:53:33 日志为固定反馈轨迹，保持学习预测、动力学、边界和执行映射不变，只改变一项代价。因为反馈轨迹不会响应新命令，这只说明控制命令的即时敏感性，不代表真实闭环效果。

| 回放条件 | 全段 ddq RMS | 冲击窗 ddq 跳变中位数 | 冲击窗总力矩跳变中位数 | 相对原版变化 |
|---|---:|---:|---:|---:|
| 原版 `q_gravity=30` | 11.297 | 34.686 | 3.879 Nm | — |
| `q_gravity=20` | 9.876 | 31.526 | 3.577 Nm | −12.6% / −9.1% / −7.8% |
| `q_gravity=15` | 9.020 | 29.864 | 3.408 Nm | −20.2% / −13.9% / −12.2% |
| `q_gravity=10` | 8.055 | 28.479 | 3.206 Nm | −28.7% / −17.9% / −17.4% |
| 关闭竖直倾角代价 | 6.217 | 20.040 | 2.397 Nm | −45.0% / −42.2% / −38.2% |

这是连续、单调的命令敏感性，证明竖直倾角代价确实在推动较强动作。其他单项消融：

- 关闭角速度代价：ddq 跳变 RMS 降 8.9%，总力矩跳变 RMS 降 7.4%。角速度抑制也会带来一部分制动动作。
- 关闭角加速度代价：ddq RMS 增 9.9%，总力矩跳变 RMS 增 5.0%。该项在当前组合中起缓和作用。
- 关闭线加速度代价：ddq RMS 增 8.7%，总力矩跳变 RMS 增 19.1%，冲击窗力矩跳变中位数增 21.0%。该项不是尖峰来源，反而在抵消一部分姿态动作。
- 关闭关节回中代价：所有变化约 0%。关节回中不是本问题来源。
- 同时关闭倾角、角速度、角加速度目标会显著平滑命令，但等于放弃项目的核心姿态任务，不能作为控制方案。

在原版回放的冲击后 60 ms 内，单步代价中位数为：竖直倾角 0.391、线加速度 0.298、角加速度 0.243、角速度 0.221、控制量 0.627。各项量纲和权重不同，数值不能直接解释为百分比贡献，但可以确认冲击时多个目标同时活跃。

## 为什么仍不能只怪姿态权重

在 `t=9.672463 s` 的肩 pitch 最大相邻总力矩变化 6.721 Nm 中，身体线加速度补偿贡献 3.482 Nm、身体角加速度补偿 0.516 Nm、`M*a` 贡献 2.720 Nm。也就是说，该尖峰约 59% 来自移动基座动力学补偿变化，约 40% 来自所选关节加速度动作。

在 `t=14.7427 s`，当前倾角约 0.44°，竖直倾角单步代价约 0.253，但角速度代价约 2.908，四个关节同时发生接近 `-15 ↔ +15 rad/s²` 的翻转。这是“刹住角运动”主导的典型事件，不是简单的“大倾角纠偏”。

## 纯仿真复核

在原仿真基线中只把 `q_gravity` 从 30 降为 20/15/10，三组均跑完 8 s、无跌倒/NaN，但均出现 QP 或执行映射回退，不能作为上机验收。`q_gravity=20` 相比原仿真基线：竖直倾角均值 0.1247°→0.1217°、自身摆动 RMS 0.1500°→0.1411°、线加速度 2.9415→2.9281 m/s²；收益很小且映射回退从 3 次增到 4 次。10/15 也没有形成稳定的综合优势。

仿真使用完整任务模板，真机使用 H0 学习预测器，两者扰动数据和处理不同；这里只能分别做各自基线内的单因素判断。

## 工程判断

当前最准确的描述是：**落脚冲击后，右臂 MPC 为维持世界竖直并抑制角运动而进行较强的主动补偿；该补偿与移动基座逆动力学前馈叠加，部分时刻会形成肉眼可见的短时震动。姿态保持是主要因素之一，但不是唯一因素。**

不建议直接切换成“冲击时锁死 PD”。固定关节仍会随身体一起平移/转动，而且突然切换会丢失或改变当前负载支撑力矩，可能制造新的阶跃。若继续优化，最有信息量的下一项是围绕 `q_gravity=20` 做专门的闭环冲击仿真和理想触发对照，并对最终总力矩变化设置连续约束；现有标准仿真尚未给出可以替换真机成功基线的方案。
