# G1 torso IMU 零点建立时机验证

目标：区分这台 G1 的 torso IMU yaw 参考更像是在开机／早期初始化时建立，还是在进入
Regular Motion Mode（`FSM=500`）时重置。该试验只读 `rt/secondary_imu` 并调用
`GetFsmId()`；不切模式、不创建 publisher、不发送关节或行走命令。

## 启动观察器

保持机器人有防跌保护并连接网线。在仓库根目录运行：

```bash
mkdir -p evaluation/hardware_shadow/commissioning/g1_imu_zero_test
/tmp/g1-commissioning-full/g1_imu_zero_observer \
  enx6c1ff701509c \
  --log evaluation/hardware_shadow/commissioning/g1_imu_zero_test/observer.jsonl \
  --permit-read-only-observer IMU_ZERO_READ_ONLY
```

程序每 0.2 秒打印一次：

```text
+12.400s fsm=4 q=[w,x,y,z] rpy_deg=[roll,pitch,yaw] dyaw_deg=...
```

- `fsm` 是 getter 实际读回；改变时显示 `<FSM_CHANGE>`。
- `dyaw_deg` 是相对观察器首帧的 yaw 变化，不是另一个传感器量。
- 相邻打印值突然变化至少 5° 时显示 `<YAW_JUMP_CANDIDATE>`，这只是提示，必须结合
  机器人是否真的转动和视频判断。
- `Ctrl+C` 正常停止并关闭日志。观察器不会代替遥控器切模式。

2026-09-16 已在本机做 3 秒实机只读冒烟测试：持续读回 `FSM=500`，yaw 从约
`-75.12°` 到 `-75.15°`，没有 jump candidate；设备构建 CTest `7/7`、默认无设备构建
CTest `6/6` 通过。二进制扫描未发现 command topic 或 `ChannelPublisher` 符号。

## 有判别力的完整流程

只在机器人有可靠防跌保护、切到阻尼后不会倒下时执行。让相机同时看到机器人朝向、
遥控器和终端。

1. 关闭机器人。把躯干朝向一个清楚的地面标记 A。测 yaw 时不需要故意
   后仰。
2. 开机并恢复网线连接。**在按任何模式键之前**启动上述观察器，稳定记录至少 5 秒。
   这是“开机后、进入运控前”窗口。
3. 在保持可靠支撑时，将整机绕竖直轴缓慢转到地面标记 B，稳定后先确认 yaw
   已明显非零。保持 B 不动，按 `L2+B` 进入阻尼；等待 `fsm=1` 并记录 5 秒。
   这样可独立判断阻尼入口是否回零。
4. 在阻尼且脚离地时，将整机缓慢转到地面标记 C，稳定并确认 yaw 明显非零。
   保持 C 不动，摆好站姿并扶稳，按 `L2+↑` 进入锁定站立；等待 `fsm=4`，
   记录 5 秒。这样可独立判断锁定站立入口是否回零。
5. 在可靠支撑下将整机缓慢转到地面标记 D，稳定并确认 yaw 明显非零。保持 D
   不动，用 `R1+X` 进入 Regular Motion Mode；等待 `fsm=500`，再记录至少 10 秒。
   这样可独立判断 Regular 入口是否回零。
6. 每次都必须先完成转向、等待静止窗口，再按模式键；不要边转边按。若模式切换时
   机身真实转动，对照切换后的长时稳定值和陀螺仪；无法区分时保留为受混杂。
7. 不需要运行 A3，也不要行走。按 `Ctrl+C` 停止观察器，然后再按现场正常流程
   处理机器人。

2026-09-16 现场已实测 `L2+B → FSM 1`、`L2+↑ → FSM 4`、`R1+X → FSM 500`；
它们与本地官方《操作指南》截图的目标机型说明相符。不将这些按键外推到其他固件。

## 判读

- 某个模式切换前 yaw 已明显非零，切换后仍保留相近非零值，且与真实小幅
  转动连续：支持该模式入口不重置 yaw。三个入口都如此时，支持参考在开机／早期
  初始化阶段已经建立。
- 进入 500 前 yaw 明显非零，机器人物理朝向又未变，但 `fsm` 变成 500 附近 yaw
  突然跳到约 0，且四元数同步跳变：
  支持进入 Regular Motion Mode 时重置 yaw。
- 进入 1 或 4 时发生跳变：零点可能建立在相应运控初始化阶段，不能归到 500。
- 开机窗口 yaw 本身不接近 0，又没有模式切换跳变：可能采用持久参考、磁航向或其他
  初始化逻辑；不能只用本流程将它归为开机朝向置零。

只比较静止窗口的 yaw 和四元数。roll/pitch 通常受重力方向约束；后仰开机不是判断 yaw
零点的必要条件，也不应把欧拉角 wrap（`+180°/-180°`）误判为真实重置。

## 2026-09-16 实测结果

首次运行没有在进入 500 前主动建立并稳定保持一个足够大的非零 yaw，而且进入自主
平衡时机身真实转动，因此**无法在“开机”和“进入 500”两个零点假设之间作出最终二选一**。
详细数值与边界见 [当次 session 记录](sessions/20260916_IMU_ZERO_REFERENCE.md)。可确认：

- 后仰开机时 pitch 直接读到约 `-6.9°`，没有把开机姿态当作完整三轴零位；
- 开机后 yaw 约 `0.2°`，说明 yaw 是局部参考，不是实验室固定绝对朝向；
- 在 `4 → 500` 附近，yaw 从约 `-6.9°` 变到约 `0.5°`，但同时测得明显角速度；
  5 Hz 抽样的陀螺仪积分已能解释约 `3.0°` 的变化，不能把剩余差值当作确证的重置。

同日的第二次试验按 B/C/D 方向分别为三个模式入口建立非零基准，得到决定性结果：

- `0 → 1`：`-85.761° → -90.634°`，没有回零；
- `1 → 4`：`-174.660° → -178.417°`，没有回零；
- `4 → 500`：`+92.824° → +92.880°`，没有回零。

因此目标机的 yaw 局部参考在开机／早期 IMU 初始化后、尚处于 `FSM=0` 时已建立；
阻尼、锁定站立和 Regular Motion Mode 入口都不重置它。
