## 只修改两件事

1. **可恢复故障退权**：查询过期、计算／预测器异常允许依靠仍新鲜有效的 LowState 和最后成功命令渐退；
   独立保留遥控接管、模式退出、tick 回退锁存，不能被更早的软故障盖住。
   不再等零速度 RPC 回复才开始故障／主动停止退权；停车请求另在线程发送。
   采用绝对周期调度，保留每帧渐变限制及最后成功包的 PD＋前馈连续性，不重新求解 MPC。
   速度 RPC 失败后完成退权仍返回错误码，不冒充操作者正常停止。
2. **性能设置统一**：PID/MPC 实际执行入口在 DDS 前复核 CPU governor 与 ACPI 平台 performance；
   MPC 按请求准备当前进程 RT 权限。使用固定系统命令和 `sudo -n`；用户必要时在同一终端 `sudo -v`。
   不收集密码、不设置永久免密 sudo、不以 root 跑 Python，不修改仿真或控制增益。
   设置前后与修改项写入 session_start；离线 preflight 不改变主机。
