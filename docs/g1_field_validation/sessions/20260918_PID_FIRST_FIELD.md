# 2026-09-18：20 ms 真机 PID 调试失败、修复与三轮复验

## 结论

首次故障轮不是有效 PID 实验。程序在 FSM 500 中完成抬臂并进入右臂 PID，约 5.02 秒开始请求前进，
约 5.35 秒因速度 RPC 失败中止。现场观察到右臂持续抖动，随后快速放下。

电脑端最终零行走速度 RPC 返回成功，进程退出后没有残留 publisher；只读复查仍为 FSM 500、
LowState CRC 拒绝数为零。操作者随后按现场流程处理机器人状态。

## 原因

- 115 个有效 PID 周期中，目标速度最大为 0.48 rad/s，约 61.2% 的关节样本达到该限制。
- 五关节目标速度合计出现 137 次符号反转，单周期目标角最大跳约 0.550°。
- 速度 RPC 超时后，旧故障清理路径从最后的 `weight=1` 单帧写到 `weight=0`。这与现场看到的
  快速放下相符；它不是设计中的三秒正常退权。

## 修复与离线证据

- 真机输出增加 0.08 rad/s 速度限制和 0.20 rad/s² 加速度限制，并从进入 PID 时的实测关节角起步。
- 正常停止、Ctrl-C 和速度 RPC 故障冻结最后目标，统一执行三秒线性退权；删除单帧零 weight 清理。
- 退权还限制每个已发布帧的最大 weight 降幅；调度卡顿只会延长退出，不会令下一帧直接降到零。
- FSM／L2+B 联锁或状态／DDS 不可用时停止发布，不和机器人自身模式争抢。
- 同一条真机记录回放后：最大输出速度 0.076 rad/s、最大输出加速度 0.20 rad/s²、符号反转 12 次、
  单周期目标角最大跳 0.087°，目标保持在名义角 ±5° 内。
- 回放结果保存在同一会话目录的 `offline_repair_replay.json`；这是离线命令验证，不是真机复验。

首次修复后曾锁定输出并安排复验；结果见下文。失败轮不得算作成功。
