# M10：空格暂停行走，继续手臂控制

M10沿用M01：双臂零中立位、左臂五关节固定PD `Kp=20/Kd=1`，右臂学习前馈MPC，
75 mm/250 g模型，6 ms，时间对齐关闭。M08的左臂双倍增益不带入M10。
MPC权重、力矩限制、关节边界、3.3～4.8 s接管不变。

## 运行

在能够接收键盘输入的启动终端运行：

```bash
cd /home/fjk/g1_ws/hold-my-beer-mpc
sudo -v
/home/fjk/miniforge3/envs/g1_mpc/bin/python \
  tools/g1_commissioning/g1_run_morning_20261013.py M10 --execute
```

按原流程输入 `EXECUTE SCHOOL_G1_20260915`。

- 0～3 s抬臂，3～5 s站立准备，5 s开始按0.5 m/s请求前进。
- 行走时**短按空格，不需要回车**：请求腿部零速度，暂停累计行走计时，手臂继续控制。
- 再短按空格：恢复0.5 m/s前进，从原累计时间继续计时。
- 可以反复暂停；暂停期间不会因为旧的18 s/21 s任务时限而退权。
- 累计前进20 s后不能再恢复行走；自动进入3 s停车稳定，再按原零速确认和至少3 s渐进退权结束。
- 按一次Ctrl+C：提前结束，走原停车及渐进退权流程。

暂停保持沿用M01：左臂固定PD，右臂继续读取实时q/dq和IMU、查询学习预测并求解MPC。
暂停不冻结预测器时间戳、不复用旧控制输出、不重新接管。H0只在第一次行走前冻结一次。
暂停的腿部指令为 `[0,0,0]`；前进和最终停车稳定阶段仍用原航向保持。
空格唤醒速度发送线程；若已有同步速度RPC在途，零速请求要等待该RPC返回。
这表示请求停车，真实脚步的减速与站稳时间由内置行走控制器决定。

20 s定义为主机调度的前进累计时间，排除暂停时间；不等于通过足底传感器测得的运动时间。
3 s准备、最终停车稳定及退权均不计入20 s。
