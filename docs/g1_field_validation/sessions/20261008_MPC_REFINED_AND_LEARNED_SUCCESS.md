# 2026-10-08 refined 与 learned MPC 首次完整成功

这份记录冻结同一新版控制器的两次完整真机走停结果：先运行不使用学习预测的
`hold_current`，再运行 `learned_filtered`。两轮都完成抬臂、前进、停车、三秒退权，
程序没有记录故障，最终 `weight=0`；操作者均确认动作平顺。学习轮中，操作者肉眼看到
右臂随身体运动进行补偿。

这证明当前两个入口可以在本机完成一轮完整流程，但**一对运行不是统计学结论**，也不是
硬实时认证。原始 JSONL 和分析产物保留在本机 `evaluation/`，Git 保存路径、哈希、配置和结论。

## 2. 同版对照结果

以下为 H0 系瓶身中心／瓶轴指标，右臂是 MPC 控制侧，左臂是固定参考侧。

| 右瓶偏离 H0 竖直 RMS | 0.601° | **0.552°** | 改善 8.1% |
| 右瓶偏离 H0 竖直 P95 | 1.031° | **0.895°** | 改善 13.2% |
| 右瓶偏离 H0 竖直最大值 | 1.751° | **1.547°** | 改善 11.7% |
| 右端角加速度 RMS | 6.527 rad/s² | **5.955 rad/s²** | 改善 8.8% |
| 右端线加速度 RMS | **2.089 m/s²** | 2.218 m/s² | 变差 6.2% |
| 右端水平线加速度 RMS | **1.714 m/s²** | 1.895 m/s² | 变差 10.6% |

学习轮的竖直姿态和角加速度更好，但线加速度更大。两轮身体本身的振动也不同：torso
线加速度 RMS 从 1.988 增至 2.147 m/s²，因此不能把全部差异归因于学习预测。
当前末端线加速度、角加速度和角速度代价仍为零；学习预测主要经未来身体姿态和重力项
影响“保持竖直”，尚不能宣称已主动压低落脚冲击。

作为历史参照，2026-10-05 的 6 ms PID 在同一 `[5,18)` 定义下，右端线加速度 RMS
为 1.896 m/s²、水平线加速度 RMS 1.580 m/s²、角加速度 RMS 5.816 rad/s²、右瓶倾角
RMS 1.899°。本轮 learned 的右瓶倾角约低 71%，但三项动态量分别约高 17%、20% 和 2.4%；
这是“更积极维持竖直、动态运动不一定更小”的权衡，不是简单的全面胜负。

仅一个样本达到 95% 以上，不是持续饱和。该点需要在后续实验中继续观察，但本轮没有触发故障。

## 4. 学习预测有没有对准

用本次未参与训练的 learned 真机日志离线核对，严格按训练／运行时契约评价：加速度与角加速度
是每个 6 ms 区间内 `T-6、T-4、T-2 ms` 三点均值，角速度是区间末端值。与“未来保持当前值”
相比，6/24/54 ms 三个预测距离的误差改善为：

| 信号 | 6 ms | 24 ms | 54 ms |
| --- | ---: | ---: | ---: |
| 线加速度 RMSE 改善 | 8.4% | 50.0% | 58.0% |
| 角速度 RMSE 改善 | 26.3% | 48.9% | 59.9% |
| 角加速度 RMSE 改善 | 12.4% | 51.7% | 57.7% |

主要加速度包络通常只落后约 2 ms，个别分量在 24/54 ms 为 4～6 ms，整体在一个控制周期内。
最强 10% 加速度区间在 24/54 ms 的向量 RMSE 比保持当前值低 52.4%/58.5%，但预测幅值中位数
只有实测的约 81%/75%。因此可以说**低频、因果滤波后的冲击包络基本对准，但幅值偏保守**；
不能说已经对准原始高频脚底冲击，因为本系统没有足底接触传感器／内置步态相位，训练目标也刻意
滤除了高频尖峰。

## 5. 当前结论与下一步

1. 将本次 refined hold 和 learned 两轮作为新版已成功基线保留，不覆盖旧版首次完整成功证据。
2. 当前不再为“能否完整走完”修改角度、力矩或 pitch 回正参数。
3. 下一项可以在**单独配置／独立实验记录**中逐步加入小的末端线加速度代价，检查前馈是否把
   已对准的预测转化为更小的实测动态量；先保留当前成功配置作为随时可回退的基线。
4. 后续比较仍使用完整 `[5,18)`，同时报告倾角、线／角加速度、约束余量和计算时间，不能只看一项。
