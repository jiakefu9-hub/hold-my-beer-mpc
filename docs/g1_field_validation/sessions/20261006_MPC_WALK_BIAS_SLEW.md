## 快速定位：这次是肩 roll，不是上次的肩 pitch

失败 QP 求解墙钟约 0.365 ms；成功活跃拍核心平均 1.625 ms、最大 2.081 ms。
**本次拒绝不是 10 ms 计算时限，也不是学习前馈耗时。**
行走只有 24 拍、其中 2 拍超期；不能拿这小段百分比当完整行走实时性成绩。

右肩 roll 的执行时刻预测值：

```text
q = 0.014208164468590686 rad = 0.81406786 deg
dq = 0.269350583001252 rad/s
外层上限 3 deg，制动包络上限 3 - 0.15 = 2.85 deg
dt = 0.006 s，最大允许减速度 a = -8 rad/s²

q_next = q + dt*dq + 0.5*dt²*a
dq_next = dq + dt*a
q_next + dq_next/6 = 3.01215554 deg > 2.85 deg
```

因此连第一预测节点都无法满足该组合约束。实测原始肩 roll 角为约 0.713°、
速度 0.243903 rad/s；**不是实测肩角已经越过 3°**。
同一约束的独立 HiGHS 全状态／输入 LP 复核：预测状态 status=2（不可行），
原始接收状态 status=0（可行）。使用 `tests/test_mpc_recovery.py` 的
`make_policy/independent_feasibility`，未改现场求解器或参数。

新模型支撑偏置平移确实已启用；最后成功拍的期望／模型肩 roll 加速度分别约
2.536/2.550 rad/s²，这一拍没有复现上次“请求减速但模型还在强烈加速”的矛盾。
但此前仍有候选预测与期望不一致的拍，**不能据最后一拍宣布执行跟踪已解决**。
