## 1. 原始证据与直接原因

现场经过见 [首次行走失败](20261006_MPC_WALK_HOLD_FIRST.md)。输入为：

`evaluation/hardware_shadow/commissioning/mpc_torque_walk_hold_20261006_151622/raw.jsonl`

SHA-256：`ea74d13c3e4c66621ea98501785146a87639379d071139580e45fb76060ce4f9`。

成功发出 13 拍活跃 MPC 命令，约 5.098 s 求解拒绝；失败 QP 只花约 0.374 ms，
**本次不是算得太慢、不是学习库查表导致，也没有实测到关节越过外层角度限位。**
操作者看到刚踏两步就平顺放臂，与停车请求、三秒渐退记录一致。

独立线性规划检查全部状态／输入约束，得到：

| 故障拍输入与约束 | 数学上是否存在可行解 |
| --- | --- |
| 原始接收 q/dq、原约束 | 有 |
| 模型预测到假定执行时刻的 q/dq、原约束 | 无 |
| 同一执行时刻状态，仅离线移除额外制动包络 | 有 |

具体是右肩 pitch 的第一预测节点：即使取最大允许减速度 −8 rad/s²，
`q_next + dq_next/6 = 5.170994°`，仍超过包络 4.85°。
这是一条保守的速度—位置组合约束，不等于实际肩角超过 +5°。
用恒定 6.4 rad/s² 减速作简单估计，停下时约 +0.919°；但这又假设所需减速度确实能执行，
**不能用这个运动学估计直接证明实际可安全制动。**

也不能把执行时刻的预测全归为虚假速度：按预测器自己的时钟原点对齐，
其前后约 −1.72/+1.17 ms 收到的右肩速度为 0.657/0.673 rad/s，预测值为 0.696 rad/s。
肩部确实在运动；这里是主机接收时刻比较，不是电机应用延迟的标定。

## 2. 为什么不能只放宽包络

在同一故障状态，仅离线去掉包络后，QP 能解，但下一层仍报“没有满足正动力学范围的候选”。
原因可独立算出来，不是候选数量不够：

- 模型右肩支撑偏置 `b` 从前一拍约 −3.413 变成 −4.200 N·m，变化约 −0.786 N·m。
- 原规则每拍只允许总力矩变化 0.300 N·m；上一拍选出的总力矩约 −2.012 N·m。
- 在该规则允许的**整个五轴力矩盒子**中，右肩预测加速度最低仍为 +11.655 rad/s²，
  超过保留的正动力学上限 10 rad/s²。不是换几个候选就能通过。
- 失败前两拍，MPC 已要求右肩 −3.669/−4.841 rad/s² 减速，
  选出力矩的模型预测却为 +9.930/+9.797 rad/s²。这说明“候选没越限”不等于“跟上期望”。

这里的 `b` 包含重力、身体运动惯性等模型项，不只是静态重力，亦不是 `tau_est` 标定值。
模型偏置的准确度仍未知；上述是代码／模型与记录之间的确定矛盾，不是独立测得真实外力。
因此没有采用“删除包络”或“放宽到能跑”的方案。

## 3. 实际修改

### 活跃 MPC：限制额外控制力矩，而不是把支撑变化一起锁住

模型关系为 `tau = M*ddq + b`。配置新增 `active_slew_reference: model_bias_relative`：

```text
原来：|tau[k] - tau[k-1]| <= rate * dt
现在：|(tau[k]-b[k]) - (tau[k-1]-b[k-1])| <= rate * dt
```

实现为先按 `b[k]-b[k-1]` 平移力矩候选范围，再与原绝对力矩限值取交集。
模型偏置缺失／非有限或交集为空仍拒绝，不静默跳过检查。
日志新增前后模型偏置、平移量、最终候选范围；审计器按同一语义独立检查。
候选拒绝时也保留这些诊断。

**这改变了保护语义，不是所有保护原封不动：总力矩可以比以前变化更快。**
短段名义模型对照中，右肩最大单次总力矩变化约 0.899 N·m，而额外控制部分仍不超过 0.300 N·m。
因此新版仍需实际验证平顺性和响应，不能只凭相同绝对上限宣布安全性等价。

未提高角度／速度／加速度／总力矩／前馈绝对上限；没有修改制动包络、QP 目标或候选算法。
6 ms、PD 增益、250 g 瓶重、状态失效／模式／遥控联锁、写前时限不变。
入场仍限制总力矩变化，正常／故障退权实现不变。默认离线迁移配置仍使用旧 `total` 语义，
只有现场配置显式启用新规则。

### 时序：先开始调姿，再走

| 时间 | 新版现场动作 |
| --- | --- |
| 0–3 s | 原抬臂、升权流程 |
| 3–4 s | 固定目标＋支撑力矩保持 |
| 4–5 s | 原地启用右臂 MPC，腿部速度仍为零 |
| 5–15 s | 行走任务才请求前进；原地任务仍零速度 |
| 15–18 s | 停车保持，MPC 继续 |
| 18 s 后 | 零速度回复及至少三秒渐退 |

提前一秒是把两个切换错开，**不保证到第 5 秒关节必然已经完全稳定**。
每拍仍须满足原检查。H0 仍在 3–5 s 取平均并于 5 s 固定；学习预测仍到行走阶段才启用，
未改预测库／时间轴。完整主要评价窗口仍为 `[5,18)`，另记录 `[4,5)` 调姿诊断。
分析器从 session 的 `mpc_start_s` 读入口；旧日志默认仍是 5 s。
