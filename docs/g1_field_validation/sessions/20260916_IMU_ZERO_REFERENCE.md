# G1 torso IMU 零点时机连续观察（2026-09-16）

## 结论

第二次只读观察在每次模式切换前都先建立了明显非零的 yaw，完整覆盖
`FSM 0 → 1 → 4 → 500`。三次切换都保留了切换前的航向，因此对这台目标 G1 可以得出：

**torso IMU yaw 参考在读回 FSM 0 的开机／早期 IMU 初始化阶段已经建立；进入阻尼 1、
锁定站立 4 或 Regular Motion Mode 500 均不会把 yaw 重新置零。**

该试验不能进一步区分“上电的哪一个具体毫秒”或内部哪个估计器初始化函数；结论的
精确边界是：第一个 `FSM=0` 只读稳定窗口中参考已存在，且后续三个模式入口不重置它。

两次观察还能确认：

- 开机时机器人后仰，torso IMU 立即读到 pitch 约 `-6.9°`；因此 roll/pitch 受重力方向
  约束，不是把开机瞬间的完整机身姿态强制定义为三轴零位。
- 机器人开机朝向由现场地面标记定义，但读回 yaw 约 `0.2°`；这与 yaw 采用本地初始
  参考相容，而不是指向实验室的固定绝对方向。

## 方法和输出边界

- 程序：`g1_imu_zero_observer`。
- 读取：`rt/secondary_imu` 的 quaternion/RPY/gyroscope/accelerometer，以及 getter-only
  `GetFsmId()`。
- 输出能力：无 `ChannelPublisher`、无命令 topic、无 mode setter。
- 停止：最后由 `Ctrl+C` 正常退出，日志结尾为 `outcome=stopped` 且
  `publisher_created=false`。

观察器每约 0.2 秒保存一个最新样本。因此陀螺仪积分只是 5 Hz 抽样下的估算；本次最终
结论主要依据每次模式切换前后的长时稳定非零窗口，不依赖单个瞬时样本。

## 第一次实测：受真实转动混杂

| 读回时刻 | FSM | 现场动作 | 切换后的稳定值（约） |
| --- | ---: | --- | --- |
| `13.409 s` | 0 | 开机后等待 getter 可用 | RPY `[2.73°, -6.93°, 0.20°]` |
| `31.234 s` | 1 | `L2+B` 阻尼 | RPY `[2.66°, -6.94°, 0.24°]` |
| `99.558 s` | 4 | `L2+↑` 锁定站立 | 后期 RPY 约 `[2.65°, 1.31°, -6.85°]` |
| `240.902 s` | 500 | `R1+X` Regular Motion Mode | 后期 RPY 约 `[0.11°, 1.60°, 0.36°]` |

`0 → 1` 时 yaw 继续保持在约 `0.2°`，没有重置迹象。`1 → 4` 后 yaw 在数秒内逐步
变到约 `-7°`，与站姿过渡中的真实身体运动相伴，不像单帧参考跳变。

`4 → 500` 附近的关键样本：

```text
elapsed    FSM    yaw       estimated yaw rate
240.497 s    4    -6.92°      +0.11°/s
240.902 s  500    -8.23°      -7.95°/s
241.104 s  500    -5.69°     +31.09°/s
241.308 s  500    +0.04°      -0.80°/s
243.330 s  500    +0.56°      -1.16°/s
```

从 `239.077 s` 到 `243.736 s`，观测 yaw 变化约 `+7.42°`；用 body-frame 陀螺仪和当时
roll/pitch 换算 yaw rate 后，5 Hz 梯形积分约为 `+2.99°`。这不足以解释全部差值，但
已证明切换时不是“物理上完全不动、只有估计器跳变”。5 Hz 日志还可能漏掉样本间的短时
角速度，所以不将约 `4.4°` 残差解读为已证实的 yaw 重置。

## 第二次实测：分别建立非零基准

第二次试验连续记录 510.16 秒。现场每次都先转动整台机器人、等待新朝向稳定，
再保持物理朝向并按模式键；观察器从始至终没有切模式或发送命令。

| 阶段 | FSM | 稳定 yaw 圆周均值 | 模式切换判读 |
| --- | ---: | ---: | --- |
| 朝后开机 | 0 | `+0.913°` | 开机／早期初始参考 |
| 朝左，阻尼前 | 0 | `-85.761°` | 明显非零基准 |
| 朝左，阻尼后 | 1 | `-90.634°` | 未回零；阻尼下机身小幅真实变动 |
| 朝前，锁定站立前 | 1 | `-174.660°` | 明显非零基准 |
| 朝前，锁定站立后 | 4 | `-178.417°` | 未回零；`+180°/-180°` 仅是欧拉角 wrap |
| 朝右，Regular 前 | 4 | `+92.824°` | 明显非零基准 |
| 朝右，Regular 后 | 500 | `+92.880°` | 未回零；稳定差约 `+0.056°` |

三个 getter 读回的转换时刻与当帧 yaw：

```text
211.054 s    FSM 0 -> 1      yaw -85.790°
340.475 s    FSM 1 -> 4      yaw -174.119°
476.891 s    FSM 4 -> 500    yaw +93.707°
```

`4 → 500` 过渡期间机身有数度的短时振荡，但稳定后回到 `+92.880°`，与切换前
`+92.824°` 一致，明确排除了“进入 500 时将 yaw 重置为零”。

## 总体判断

- yaw 零点是开机／早期初始化后的局部参考，不是实验室绝对方向。
- `FSM 1`、`FSM 4` 和 `FSM 500` 入口都不重置该参考。
- 四元数和 yaw 会连续保留整机相对开机早期参考的航向变化；欧拉 yaw 在
  `±180°` 会 wrap，不代表四元数跳变或参考重置。
- roll/pitch 仍主要由重力方向约束，不能把开机时的完整机身姿态解释为固定世界坐标系。
