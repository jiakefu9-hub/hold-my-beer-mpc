# 10 s 前进＋3 s 停车仿真

当前论文三组仿真与真机均以前进请求开始为零点，10 s 请求停车、13 s 结束评价。新场景由 `protocol.py` 统一采集、模板与在线运行时序；`full_template.py` 保留原 11＋4 初态设计，`simulation_entry.py` 接入原仿真链和既有当前角速度外推规则，`metric_packager.py` 沿用原五项指标定义。

已完成的结果、限制和三条回放命令见[结果说明](../../../docs/simulation/experiments/20261117_walk10_stop3/README.md)。回放使用 `replay.py D01/D02/D03`，实际时长 13 s；`--check` 核对，`--once` 单次播放。旧仿真入口与数据已清理；当前入口所需共享模块集中保留于本目录。

原生运行库由 `bash cpp/build_runtime.sh` 构建。`run.py` 会采集完整 11＋4 并运行三组，已有最终清单时拒绝覆盖。本目录只有仿真与保存状态回放入口，不导入机器人 SDK 或连接机器人。

如需独立重新采集和运行，使用 `run.py --variant <新名称>`；默认已完成结果拒绝覆盖。

## 固定机位与截图

```bash
/home/fjk/miniforge3/envs/g1_mpc/bin/python tools/experiments/thesis_walk13/replay.py D01 --paused
```

回放旁会打开 `G1 replay - camera and screenshots` 控制面板。相机的方位角、俯仰角、距离、视野角、观察目标位置和窗口宽高均可输入；按 `Apply numbers` 应用。鼠标仍可旋转、平移、缩放，面板实时显示新参数。手动输入尚未应用时不会被实时刷新覆盖；`Use current mouse view` 可恢复显示当前实际机位。

面板默认采用 24 像素字体，并增大输入框和按钮；顶部 `A +`／`A -` 可在 16–38 像素之间继续调整。内容较长时可用面板右侧滚动条或鼠标滚轮浏览。此设置只改变控制面板大小，不改变相机、渲染文字或机器人实际角度。修改程序后须重开回放，已打开的旧窗口不会自动更新。

- `Save camera`／`F5`：保存当前机位和窗口尺寸到项目下 `evaluation/replay_presentation/camera.json`。之后打开 D01、D02、D03 均自动载入同一份机位；`Load camera`／`F9` 可随时恢复。
- 按 `1`、`2`、`3` 或面板中的方法按钮：在同一个窗口切换 D01、D02、D03，暂停并保持当前任务时刻和相机。只需调一次机位。
- 时间框输入秒数后按 `Go / pause`：定位并暂停；方向键左右或 `Previous frame`／`Next frame` 按 2 ms 保存帧逐帧移动。在渲染窗口中按住左右方向键可连续后退／前进，松开即停止；连续移动采用系统键盘重复速度。
- `Take screenshot`／`S`：暂停并保存当前画面到 `evaluation/replay_presentation/screenshots/`。名称包含方法、任务时间和创建时间，例如 `D01_t007.250_20261118_102704_399961.png`。PNG 只有渲染画面与左右臂控制方法、倾角标签，不显示 `t = … s`，不含窗口边框和控制面板；旁边的同名 JSON 保存相机、任务时间和源轨迹哈希。成功后面板及终端显示文件名／完整路径。
- 距离和视野角决定取景大小；窗口宽高决定画面尺寸。三方法对照保持这些值一致。
- 新机位默认 **1000 × 1000、1:1**。`Window ratio` 可选 1:1、4:3、16:9，按当前宽度调整高度；也可手动输入宽高后 `Apply numbers`，使用自定义比例。`Lock ratio` 默认勾选，拖动窗口边缘时保持当前比例。`Recommended size: 1000 x 1000 (1:1)` 一键恢复推荐尺寸，保留相机位置。窗口尺寸与比例锁定状态一起保存在机位文件中，切换方法继续沿用。
- 已保存的旧机位仍使用原来的窗口尺寸，不自动覆盖；如需采用新推荐值，点击推荐尺寸按钮后再 `Save camera`。截图按实际渲染区像素保存，三张应使用同一尺寸与同一显示器。
- `Playback speed` 区域新增 **0.05x、0.1x、0.25x、0.5x、1x** 按钮，点击立即生效；也可输入正数后 `Apply speed`。例如 0.1x 是十分之一速度，便于暂停观察。速度只改变回放经过保存轨迹的快慢，控制面板里的时间仍是原始任务秒数；切换方法后速度保持不变。暂停后仍可用前／后帧按钮按 2 ms 原始采样逐帧挑选。
- `C` 可重新打开关闭的控制面板；`--no-controls` 启动时隐藏面板。空格播放／暂停，`R` 从零重播，`G` 开关方向辅助线，`Esc` 关闭回放。

也可指定 `--camera <JSON路径>`、`--time 7.25 --paused`、`--width 1000 --height 1000`、`--speed 0.1`、`--screenshot-dir <目录>`。既有 `--render-check <PNG路径>` 支持相同的机位、时间和画面尺寸参数，可离线导出精确时刻静帧。未提供 `--time` 时，该选项保留原来在任务 5 s 渲染一帧的行为。

机位文件和截图只保存在本地忽略的 `evaluation/`，不会改变归档轨迹、模型、指标或控制器。鼠标平移后的偏移会随机器人平移保留，不再在下一帧被自动居中覆盖。
